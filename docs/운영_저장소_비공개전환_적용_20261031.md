# 저장소 비공개 전환 — 운영 적용 절차 (2026-10-31)

이 저장소를 **비공개로 돌린다.** 공개 범위에서 벗어난 자료가 섞여 있다는 판단이고, 결정은
사용자가 내렸다. 전환 자체는 GitHub 설정에서 사람이 한다 — 이 문서는 그 전후로 깨지는
받는 쪽을 정리한다.

**이 문서를 전환 **전에** 올려 두는 이유.** 비공개로 돌린 뒤에는 익명으로 이 저장소를 읽을 수
없다. 운영 박스가 이 절차를 읽을 수 있어야 하므로 전환 전에 저장소에 들어가 있어야 한다.

이 문서에는 토큰 값·비밀번호·내부 주소를 적지 않는다. 자리와 이름만 적는다.

## 1. 순서 — 이 순서를 지킨다

| # | 누가 | 무엇을 | 왜 이 순서인가 |
|---|---|---|---|
| ① | 운영 박스 | 지금 판을 먼저 받는다(`update-all`). 받은 뒤 `materialtwin-web.def` 의 `upstream commit` 이 `a3563b6` 인지 본다. | 공개인 동안 받아 두면 전환 뒤 받기가 막혀도 **받은 SIF 로 계속 뜬다.** 지금 GitHub main 과 Drive SIF 의 커밋이 같아 재빌드 없이 받는다. |
| ② | 사용자 | GitHub 에서 저장소를 비공개로 돌린다. 저장소 이름은 **`squall321/MaterialTwinWeb`** 이고, 자리는 `Settings → General → Danger Zone → Change repository visibility → Make private` 이다. | 계정 설정이라 사람만 할 수 있다. 이 세션에는 GitHub 인증이 없다(`gh auth status` 가 계정을 못 낸다). |
| ③ | 운영 박스 | 읽기 전용 토큰을 둔다(§3). | 전환 뒤 통합 작업 폴더의 `clone`·`fetch` 가 익명으로는 실패한다. |
| ④ | 운영 박스 | 검증한다(§4). | 받기가 다시 되는지, 경고가 멈췄는지 확인한다. |

**①을 건너뛰면 어떻게 되는가.** 앱이 멈추지는 않는다. 받기가 막히면 스캐너가
`source_unavailable` 로 적고 **이미 받은 SIF 로 띄운다.** 다만 로그·감사·운영자 알림에
경고가 계속 나가고, 그 판이 최신인지 확인할 길이 없어진다.

## 2. 비공개 뒤 깨지는 것 — 실측으로 센 목록

| 대상 | 영향 | 조치 |
|---|---|---|
| 운영 박스의 통합 작업 폴더 받기 (`.portal/manifest.yaml` 의 `source.url` 이 GitHub 주소다) | 익명 `clone`·`fetch` 실패 | §3 토큰 |
| Drive SIF 열쇠 대조 (`upstream commit` 과 받은 커밋 비교) | 받기가 막히면 커밋을 못 읽어 열쇠 대조가 공백이 된다 | ①을 먼저 하면 지금 판으로 맞아 있다 |
| 개발 박스 | 영향 없다 — 그쪽 작업 폴더는 로컬 경로(`file://`)로 짓는다 | 없음 |
| 릴리스 묶음 스크립트 | 영향 없다 — 로컬 `git archive` 다 | 없음 |
| 카탈로그 DB 의 프로비넌스 | 이 저장소 주소를 출처로 적은 **출처 4건 · 물성값 343행**의 링크가 익명으로 열리지 않는다. **값·단위·조건·tier 는 영향 없다** — 사내에서 열면 그대로 보인다 | 그대로 둔다. 값을 고치는 것이 아니라 열람 권한 문제다 |
| `resolve_dois.py` · `fix_source_metadata.py` 의 User-Agent 문자열 | 영향 없다 — Crossref 에 신원을 밝히는 문구일 뿐 이 저장소를 받지 않는다 | 없음 |

## 3. 토큰 — 어디에 어떤 권한으로

- 종류는 **fine-grained personal access token** 이고 **이 저장소 하나만** 고른다.
- 권한은 **`Contents: Read-only`** 하나로 충분하다. 쓰기·관리 권한을 주지 않는다.
- 두는 자리는 운영 박스의 **허브 비밀 파일**이다(저장소에 커밋하지 않는다). 허브가 이미
  쓰는 관례를 그대로 따르고, 환경변수 이름은 허브 쪽 관례에 맞춘다.
- 저장소 주소를 토큰이 박힌 형태로 바꾸지 않는다. 주소에 토큰을 넣으면 **로그·프로세스
  목록·에러 메시지에 그대로 찍힌다.** 자격증명 헬퍼나 환경변수로 넣는다.
- 만료일을 둔다. 만료되면 ①의 상태로 돌아가 **앱은 뜨고 경고만 난다** — 복구가 급하지 않다.

## 4. 검증 — 이 넷을 본다

1. 통합 작업 폴더에서 받기가 되는지(스캐너 로그에 `source_unavailable` 이 없다).
2. `materialtwin-web.def` 의 `upstream commit` 이 `a3563b6` 인지.
3. 앱이 뜨고 `/api/health` 가 응답하는지.
4. 재료 카드 내보내기가 **절 여러 개**로 나가는지. 전환과 무관하게 이번 판의 고침이다 —
   예전에는 본문을 6만 자에서 자르고 「본문 절단」 표지를 붙였다. 지금 판은 자르지 않는다.
   재료 2,822종으로 미리 재 봤다. 표지가 붙던 카드 **153장**이 절 분할로 나가고, 한도를
   넘는 절 **0장**, 절을 이어 붙여 원문과 달라진 카드 **0장** 이다.

## 5. 이 문서 밖에 남은 일

- 데이터 쪽 정리(카탈로그 노트 일부 문구와 그에서 나온 허브 카드)는 **사용자 승인 전까지
  하지 않는다.** 되돌리기 어려운 변경이다.
- 이미 받아 간 사본·캐시·포크는 비공개 전환으로 되돌려지지 않는다. 사용자가 그 점을
  알고 이 선택을 했다.
- 앞으로의 규율. 사내 비공개 문서는 **경로·절 번호를 노트나 보고서에 적지 않는다.**
  근거가 필요하면 공개 문서(논문·특허·벤더 시트)로 대체 표기한다.
