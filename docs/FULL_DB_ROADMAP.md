# DB를 다 채우면 무엇을 할 수 있는가

"다 채운다"를 막연히 두면 답이 구호가 된다. 여기서는 **채워야 할 것을 물성 단위로 특정하고**,
그것이 열어 주는 해석을 단일 물리 → 복합 시나리오 순으로 적는다.

기준일 2026-08-05 · 재료 425종 · 물성값 11,285건 · 물성 정의 128종

---

## 0. "다 채운다"의 정의

세 가지가 다르다. 섞으면 계획이 안 나온다.

| 구분 | 뜻 | 현재 |
|---|---|---|
| **A. 커버리지** | 이미 있는 키를 모든 재료에 채우는 것 | 정의 128종 중 126종에 값 존재, 재료별로는 듬성듬성 |
| **B. 키 신설** | 담을 자리 자체가 없는 물성을 만드는 것 | 아래 11종이 없다 |
| **C. 함수화** | 단일 값이 아니라 **곡선·표**로 담는 것 | 대부분 상온 단일값 |

**C가 가장 중요하고 가장 덜 돼 있다.** 복합 시나리오는 거의 전부 "온도의 함수", "시간의 함수",
"변형률속도의 함수"를 요구하는데, 지금은 상온 스칼라가 대부분이다.

## 3. 단일 물리 — 다 채웠을 때

낙하·열전달·열응력·결로·접착·EMI는 [SIMULATION_CAPABILITY.md](SIMULATION_CAPABILITY.md)에 있다.
여기서는 **다 채웠을 때 달라지는 것**만 적는다.

- **낙하** — 파단연신율 근사가 아니라 삼축도 의존 파괴로 간다. 어디가 먼저 깨지는지가
  기하·하중 조건에 따라 달라지는 걸 볼 수 있다.
- **열해석** — 온도의존 k·cp가 들어가면 SoC 고온부(80~100 °C)의 예측이 실제로 맞는다.
  지금은 상온 k로 전 구간을 푼다.
- **결로** — 4단계(WVTR·확산·Csat)가 채워지면 **밀폐 공간 내부 결로**를 푼다.
  카메라 모듈 내부, 배터리 팩 내부, 스피커 캐비티가 대상이다.
- **접착** — 응집영역(GIC/GIIC)이 들어가면 박리가 **어디서 시작해 어디까지 번지는지**를 본다.

## 4. 복합 시나리오 — 여기가 본론

복합 시나리오는 **해석 A의 결과가 해석 B의 초기조건이 되는 사슬**이다.
사슬은 가장 약한 고리에서 끊어지므로, 각 시나리오마다 끊어지는 지점을 명시한다.

### 4.1 리플로우 → 워피지 → 낙하  **[거의 가능]**

```
온도이력 → CTE·E(T) → 잔류응력·휨 → (초기조건 이관) → 낙하
```

지금까지 낙하는 무응력 상태에서 시작했지만 실제 기판은 리플로우 잔류응력을 안고 있다.
워피지 해석 결과를 `*INITIAL_STRESS`로 넘기면 낙하 예측이 달라진다.

**끊어지는 고리** — `E(T)`, `CTE(T)`가 상온 단일값이다. 리플로우는 25 → 260 → 25 °C를 지나고
EMC·솔더마스크는 Tg 위에서 CTE가 3배로 뛴다. Tg 위아래 CTE 두 값(α1, α2)과
온도별 탄성률이 필요하다. → **C(함수화)** 문제다.

### 4.2 온도사이클 → 솔더 열피로  **[절반 가능]**

```
온도사이클 → Anand 점소성 → 사이클당 비탄성 소성일 ΔW → Darveaux → Nf
```

앞단은 된다. SAC305 Anand 9상수 완성 세트 5개가 있고, 그중 Zhang 2018 세트는
25~200 °C·10~75 /s로 범위가 넓다.

**끊어지는 고리** — Darveaux K1~K4와 Coffin-Manson εf′·c가 **키조차 없다.**
ΔW까지 계산해 놓고 사이클 수로 환산을 못 한다. 이 두 키만 채우면 즉시 수명 예측이 된다.

### 4.3 고온고습(85/85) → 물성저하 → 낙하  **[불가]** ← 가장 어려움

```
85 °C/85% RH → 수분확산 D → 포화농도 Csat → 흡습팽윤 CHE → 계면 열화
  → 노화 후 물성 → 낙하
```

이 사슬은 **네 고리가 동시에 끊겨 있다.**

| 고리 | 필요 | 현재 |
|---|---|---|
| 수분 확산 | D(T) | 5종, 온도의존 없음 |
| 포화 농도 | Csat | **키 없음** |
| 흡습 팽윤 | CHE | **키 없음** |
| 노화 후 물성 | 유지율(t, T, RH) | **키 없음** (정성 서술 88건뿐) |

지금 있는 `hydrolytic_stability`·`chemical_resistance` 88건은 "양호/불량" 수준의 서술이라
해석 입력이 못 된다. 정량화하려면 **시간축이 있는 데이터**가 필요하다 —
예를 들어 "1000 h 후 인장강도 유지율 82%" 같은 형태.

**이걸 채우는 게 이 로드맵에서 가장 값어치 있다.** 스마트폰 신뢰성 시험의 상당수가
85/85 후 낙하·굽힘이고, 지금은 그걸 해석으로 전혀 못 본다.

### 4.4 반복 낙하 → 피로파괴  **[불가]**

```
낙하 1회 응력이력 → 사이클 누적 → 손상 D → 파단
```

`fatigue_strength` 38건은 **단일 피로한도**라 "이 응력이면 무한수명" 판정만 된다.
실제로 알고 싶은 건 "1.2 m 낙하 500회면 깨지는가"인데, 그건 S-N 곡선이 있어야 한다.

**끊어지는 고리** — Basquin σf′·b (키 없음). 금속은 문헌이 많아 채우기 쉽고,
접착층·폴리머는 훨씬 적다.

### 4.5 폴더블 20만 회 폴딩 → 크리스 잔류  **[제한적]**

```
반복 굽힘 → 점탄성 완화 + 점소성 축적 → 영구 변형(crease)
```

3M CEF3501은 −25/25/55/85 °C × RH 0/90%의 Prony 5세트가 있어 **온습도별 회복 거동**까지
볼 수 있다. 폴더블 해석에서 이만한 데이터가 있는 재료는 드물다.

**끊어지는 고리** — Prony 보유가 11종뿐이고, 반복 하중의 **누적 소성**을 담을 키가 없다.
점탄성만으로는 20만 회 뒤 잔류를 못 낸다 — 점소성 또는 손상 누적이 필요하다.

### 4.6 결로 → 부식 → 전기 단락  **[절반 가능]**

```
표면 결로 → 전해질 막 형성 → 갈바닉 쌍 → 부식 → 저항 변화·단락
```

갈바닉 전위 53건이 **기준전극과 전해질을 조건에 달고** 있어 이종금속 쌍의 구동력은 계산된다.
접촉각 29종으로 물막이 어디에 맺히는지도 본다.

**끊어지는 고리** — 부식률 8건. 게다가 부식률은 **갈바닉 쌍 의존값**이라 단일 재료 물성으로
담기 어렵다(그래서 MIL-STD-889D 표를 폐기했다). 쌍(pair) 단위 테이블이 필요할 수 있다 —
이건 스키마 확장 논의가 먼저다.

### 4.7 배터리 스웰링 → 구조 변형 → 접착 박리  **[불가]**

```
충방전 사이클 → 전극 팽창 → 셀 두께 증가 → 하우징 응력 → 접착층 박리
```

**끊어지는 고리** — SOC·사이클 함수로서의 팽창률 키가 없고, 접착 박리 전파(GIC/GIIC)도 없다.
배터리 재료 10종은 열해석은 되지만 기계·전기화학 연성은 안 된다.

### 4.8 낙하 → 실링 파괴 → 침수  **[불가]**

```
낙하 충격 → 가스켓 순간 압축 해제 → 틈 발생 → 방수 등급 상실
```

**끊어지는 고리** — 압축영구변형(compression set)과 마찰계수가 둘 다 키가 없다.
가스켓 초탄성 계수는 있어서 정적 압축은 되지만, 충격 중 순간 이탈은 마찰 없이 못 푼다.

### 4.9 장기 크리프 → 카메라 모듈 처짐  **[불가]**

크리프율 6종, Norton 상수 0건. 상온 장기 크리프는 데이터 자체가 희소하다.

## 6. 다 채웠을 때 질적으로 달라지는 것

물성 개수가 아니라 **해석의 성격**이 바뀐다.

1. **단발 해석 → 사슬 해석.** 리플로우 잔류응력을 안고 낙하하고, 85/85를 겪은 물성으로
   굽힌다. 지금은 각 해석이 서로를 모른다.
2. **합불 판정 → 수명 예측.** "이 응력이면 견딘다"에서 "몇 사이클에 깨진다"로.
   피로·크리프·손상 누적이 들어가야 가능하다.
3. **시험 대체가 아니라 시험 설계.** Arrhenius Ea가 있으면 가속시험 조건을 해석으로 정하고,
   시험은 검증에만 쓴다.
4. **재료 치환의 정량 비교.** 커버글래스 코팅을 바꾸면 결로가 얼마나 줄고, 라미네이트를
   바꾸면 워피지가 얼마나 주는지를 같은 척도로 비교한다.

## 7. 채워도 못 하는 것

정직하게 적는다. 물성 DB로 해결되지 않는 영역이 있다.

- **제조 편차** — 접착 두께 산포, 리플로우 프로파일 편차, 조립 공차. 확률론적 해석이
  필요하고 이건 물성이 아니라 **공정 데이터**다.
- **결함 의존 파괴** — 유리 파단은 표면 흠집 분포가 지배한다. 파괴인성만으로는 못 푼다
  (Weibull 통계가 필요하다).
- **접촉·마찰의 실제 상태** — 산화막·오염·표면조도가 지배하는데 문헌값은 이상적 표면 기준이다.
  이 카탈로그가 표면처리 불명 금속의 접촉각을 버린 것도 같은 이유다.
- **다중물리 연성 자체** — 물성이 다 있어도 솔버가 순차·양방향 연성을 지원해야 한다.
  이건 DB가 아니라 해석 환경 문제다.
