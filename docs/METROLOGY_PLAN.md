# 시험장비 카탈로그 → 측정법 안내 (계획)

## 무엇을 만드나

`/data/paper_patent_corpus/metrology_catalogs` 의 **장비 카탈로그 80편(9분류, 251 MB)** 을
카탈로그에 편입해, **"이 물성을 어떻게 재나"** 에 답하게 만든다.

**PDF 목록을 보여 주는 게 목적이 아니다.** 값은 연결에 있다 —

```
property_key(204종)  →  측정법(기법 + 시험규격)  →  장비(제조사·모델 + 인쇄된 사양)
```

물성 카탈로그가 이미 "무엇이 얼마인가" 에 답한다.
여기에 **"그걸 무엇으로 어떻게 재는가"** 를 붙이면, 빈 칸을 만난 사용자가
**다음에 무엇을 할지** 알게 된다. 이게 이 기능의 존재 이유다.

## 왜 지금인가

물성 수집이 31,639값에 이르렀는데 **해석 격자에 2,721칸이 비어 있다.**
그중 상당수는 문헌에 없어서 비었다 — 즉 **직접 재야 하는 칸**이다.
그 칸을 클릭했을 때 "이건 레이저 플래시로 잰다, ASTM E1461, 우리 카탈로그의 NETZSCH LFA457 은
−125~1100 °C 를 커버한다" 가 나와야 한다.

## 설계 결정

### 표는 둘이면 된다

| 표 | 무엇 |
|---|---|
| `instrument` | 제조사 · 모델 · 분류 · 카탈로그 PDF(→ `source`) |
| `instrument_capability` | 장비 × `property_key` × 기법 × 규격 + **인쇄된 측정범위·분해능·온도범위** |

측정법을 별도 표로 빼지 않는다. **기법과 규격은 능력행의 속성**이지 독립 개체가 아니다
(CLAUDE.md §2 — 단일 용도에 추상화를 만들지 않는다).

### 카탈로그 PDF 는 `source` 로 들어간다

`kind='datasheet'` 로 이미 어휘에 있다. **값의 프로비넌스 규율을 그대로 쓴다** —
장비 사양도 "인쇄된 것만" 이고, 근거는 출처로 남는다.

### 규율은 물성 수집과 같다

- **지어내지 않기.** 카탈로그에 인쇄된 사양만. "이 장비면 이 정도 될 것" 은 값이 아니다.
- **빈 칸이 틀린 값보다 낫다.** 범위가 안 적혔으면 비운다.
- **조건 없는 값은 값이 아니다.** 측정범위는 **단위와 함께** 아니면 안 넣는다.
- **벤더 문구를 값으로 읽지 않는다.** `industry-leading` · `up to` 는 사양이 아니다.
  `up to 1100 °C` 는 상한만 확정하고 하한은 비운다.
- **규격번호가 기법을 정한다**(브리프 242·252번). 카탈로그가 `ASTM E1461` 을 인쇄하면 그게 확정이고,
  본문의 기법 명칭은 보조다.

### 물성 매핑은 우리가 판단한다

카탈로그는 `property_key` 를 모른다. `Thermal diffusivity` 를 `thermal.diffusivity` 로 잇는 것은
우리 판단이므로 **`mapping_confidence`** 를 남긴다. 애매하면 안 잇는다.

## 화면

`/metrology` — 좌: 도메인·물성 선택 / 우: 그 물성을 재는 **기법 → 장비** 표.
물성 카탈로그의 빈 칸에서 **"어떻게 재나"** 로 넘어오는 링크를 붙인다.

## 범위 밖 (이번에 안 하는 것)

- PDF 원문 뷰어 — 파일이 251 MB 이고 재배포 라이선스가 불명이다. **경로만 기록**한다.
- 장비 가격·납기 — 카탈로그에 없다.
- 시험소 정보 — 다른 데이터다.
