08

금지 규정

예외 없이 적용하는 7개 항

  1. 지어내지 않는다

    빈칸이 틀린 값보다 우선. 문서에 실제 인쇄된 숫자만 등재.

  2. 역산 금지

    타 물성 유도값 저장 금지. 원문이 수행한 계산만 인용.

  3. 그래프에서 읽지 않는다

    축 눈금과 스캔 해상도가 유효숫자를 결정 — 판독 자릿수는 우리가 만든 값.

  4. 재인쇄본·2차 인용 불가

    인용값은 1차 출처까지 추적해 확인.

  5. 조건 없는 값은 값이 아니다

    온도·주파수·방향·습도 미기재 시 해석 입력 불가.

  6. 자릿수 대조

    동일 재료의 상위 tier 값과 자릿수 불일치 시 등재 보류.

  7. 인접 열 오독 주의

    표는 한 열이 통째로 밀릴 수 있음. 대조군 행과 본문 서술로 검산.

각 규칙은 실제 적발 이력을 근거로 한다. 규칙 4는 「3M 인쇄값 0.49」로 기재된 43건의 근거가 계열 기술자료였음을 적발했고, 규칙 6은 1,000배 과대 굽힘강도 2건을 차단했다.
