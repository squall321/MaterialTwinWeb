# 물성 데이터 구축 히스토리

MaterialTwin 카탈로그가 **0 → 5,963 물성값** 으로 채워진 과정과, 그 과정에서
정한 규칙·발견한 함정을 기록한다. 커밋 단위 변경은 git log에 있으므로, 여기에는 **왜 그렇게
했는지**와 **다시 할 때 알아야 할 것**만 남긴다.

최종 상태(2026-08-03): 재료 425종 · 물성값 10,924(실측 6,566 · 핸드북 1,617) · 출처 1,267(DOI 233) ·
**물성 정의 119/119 전부에 값 존재** · **추정값만 있는 재료 0종** · **출처 없는 값 0건**.
DYNA 입력 커버리지 — 밀도 91.2% · 영률 87.5% · CTE 91.2%.

## 단계별 경과

### 0단계 — 스키마 (커밋 `31a668c`)
`property_definition`(91개 taxonomy) · `source`(프로비넌스) · `property_value`(값+조건+등급) 3테이블.
설계 결정 하나가 이후 전부를 좌우했다 — **출처 없는 값은 저장 자체를 거부**(`register_property`가
source_doi/url/title 중 하나를 요구). 덕분에 끝까지 "출처없음 0"을 유지했다.

### 1단계 — 스마트폰 재질 카탈로그 (193종 / 1,429값)
AIDataHub의 HW 에이전트 도메인을 커버리지 체크리스트로 삼아 스마트폰 내부 재질을 수집.
그레이드 단위 충실도를 목표로 함(예: "광학 플라스틱"이 아니라 `APEL 5014CL (COC, Mitsui)`).

### 2단계 — 조회 수단 (`0c77c4c` ~ `ecd8b9f`)
데이터가 있어도 볼 수단이 없으면 죽은 데이터다. 순서대로 카탈로그 UI → 재료 비교(최대 12종)
→ Ashby 산점도 → LS-DYNA 카드 출력. **웹과 MCP가 같은 코어를 공유**(`catalog_compare.py`,
`dyna_export.py`)해 화면과 에이전트 답이 갈리지 않게 했다.

### 3단계 — 출처 실체화 (`ea1ba75`, `c0ac85a`)
journal 출처 174건 중 DOI가 12건뿐이었다. CrossRef API로 제목 검색 → **DOI 6% → 100%**.
지어내지 않기 위해 세 겹 필터: 제목 유사도 ≥0.92 + 원저널/학회 논문 종류 + **인용수**.
인용수 기준이 결정적이었다 — 재수록본(World Scientific 챕터, 인용 9)이 원저(Nature Materials
`10.1038/nmat732`, 인용 2797)를 밀어내는 걸 막았다.

### 4단계 — 해석 입력 물성 (`cc73ced`, `9eadc69`, `3aa52ea`)
DYNA 카드에 필요한 6종(밀도·영률·포아송비·비열·열전도·CTE)이 19~89%로 구멍이 많았다.
계열 규칙으로 99~100%까지 채우되 **tier4(계열 추정)로 정직 표기**.
이어서 흡습률·방사율·아웃가싱 등 비-DYNA 물성도 보강.
σ-ε 곡선은 스칼라에서 **합성**하되 그래프에 `[실측]`/`[합성]`을 명시하고 출처를 함께 렌더.

### 5단계 — 추출 도구 (`62d934d`)
업체 데이터시트가 Illustrator로 만든 **이미지 전용 PDF**인 경우가 많아 `pdftotext`로는 0자였다.
- `scripts/catalog/extract_datasheet.py` — 텍스트 레이어 우선, 비면 300dpi 렌더 후 OCR 폴백
- `scripts/catalog/digitize_curve.py` — 그래프 이미지 → 좌표 CSV
설치 직후 Kuraray FCCL 브로슈어(텍스트 0자)를 OCR로 뚫어 물성표 전체를 얻었다.

### 6단계 — 벤더 병렬 수집 (`20c0204` ~ `18c8e7d`)
10개 에이전트를 벤더 영역별로 나눠 투입. **에이전트는 DB에 직접 쓰지 않는다** —
SQLite 락 경합을 피하고 등록 전 검토 지점을 만들기 위해 JSON으로 내놓게 하고,
메인이 `scripts/catalog/ingest_agent_json.py`로 검증 후 직렬 등록.
벤더 60곳 이상 · 1,662건 실측 확보.

### 7단계 — 논문 기반 보강 (`0ec5b02` 외)
실측 0건 재료가 137종 남았는데 대부분 반도체·세라믹·MEMS로 **애초에 벤더 데이터시트가 없는**
것들이었다. 전략을 논문(DOI)으로 전환 → 137 → 84종. 마지막 빈 물성 7개까지 개통해 **91/91 달성**.

### 10단계 — 화면이 데이터를 못 따라간 것 (`4d80f32` ~)

물성만 잔뜩 늘리는 동안 **화면은 시험 중심 그대로**였다. 재료가 193 → 295로 늘고
신규 재료는 전부 물성만 있는데, 재료 목록이 최신순(`id desc`)이라 첫 페이지가
전부 신규 재료로 채워졌고 들어가면 "시험 데이터가 없습니다"만 떴다. 앱 전체가
빈 것처럼 보였지만 시험 73건·곡선 73·피팅 171은 멀쩡했다.

- 재료 상세: **시험 유무와 무관하게** 물성 섹션을 항상 렌더. 시험이 있으면 곡선·피팅
  아래에 물성이 이어지고, 없으면 물성만 나온다. 둘 다 없을 때만 업로드 안내
- 재료 목록: "시험 n"/"물성 n" 배지 + `has_tests` 필터
- 카탈로그 상세 ↔ 재료 상세 교차 링크
- **교훈: 데이터를 크게 늘렸으면 그 데이터가 화면에서 어떻게 보이는지 확인할 것.**
  집계 필드를 목록에 넣을 때는 페이지 내 재료만 group by로(N+1 금지).

**정합성 점검 14항목**(마무리 때 매번 돌릴 것) — 출처 없는 값 / 끊어진 참조 /
정의 없는 키 / 값·텍스트 모두 없음 / 단위 불일치 / tier 범위 / method 어휘 /
출처 kind 어휘 / **category 어휘** / 물성값 0인 재료 / 추정만 있는 재료 /
제목 없는 출처 / **journal인데 DOI 없음** / **conditions가 dict 아님**.
마지막 세 개가 실제로 걸렸다. 이후 **고아 시편** · **항복 ≤ 인장** · **초탄성의 model 조건** ·
**광학값의 파장 조건** 검사를 더해 18항목이 됐다.

**파장 없는 굴절률·반사율 75건** — 파장은 이 물성의 정의 조건이라 없으면 값 자체가 해석 불가다.
노트에 파장이 적혀 있던 6건은 조건으로 구조화하고, 나머지는 tier4로 내려 대표값으로
뽑히지 않게 했다(지우지는 않았다 — 파장이 확인되면 되살릴 수 있다).

**항복 > 인장이 10건 나온다.** 값 각각은 출처가 있는데도 조합이 물리적으로 불가능한 이유는,
**대표값을 물성마다 독립으로 고르기 때문**이다. PC/ABS는 항복이 CYCOLOY C2950, 인장이
Cycoloy C1200에서 왔고, 동박은 항복이 IPC-4562A 추정치인데 인장은 18 µm 실측이다.
곡선 합성은 이 조합을 그대로 쓰면 안 되므로 `curve_synth._consistent_yield_uts()`가
같은 재료 안에서 항복 ≤ 인장을 만족하는 최선 조합으로 바꾸고 그 사실을 노트에 남긴다.
근본 해결은 **결합된 물성을 같은 출처에서 함께 뽑는 것**인데, 대표값 규칙 자체를
바꾸는 일이라 아직 하지 않았다.
- `category`에 어휘 밖 값(`organic`·`semiconductor`·`liquid`)이 16건 — DB에 CHECK가
  없어 MCP 경로로 들어왔다. **어느 분류 칩에도 안 잡혀 화면에서 사라지고 있었다.**
- DOI 없는 `journal` 6건 — arXiv 2건은 DataCite에 등록된 DOI(`10.48550/arXiv.*`)를
  제목 대조 후 부여, 학회 자료집·기업 기술지 4건은 색인 저널이 아니라 `other`로 재분류
- `conditions`가 dict가 아닌 서술 문자열 61건 — 조건 비교·중복 판정이 무력화되므로
  `{"detail": ...}`로 감쌌다

### 9단계 — 등급 정규화와 마지막 빈 칸 (`eb0cc7e` ~)

수집이 끝난 뒤 **같은 성격의 값이 두 등급에 갈려 있는 것**이 드러났다.
벤더가 자기 제품에 인쇄한 시험값이 기존에는 tier1인데, 8단계 수집에서는 tier3으로 들어갔다.
대표값 선택이 최저 tier를 고르므로 조회 결과가 갈렸다.
`normalize_tiers.py`로 3단계 판정 — 데이터시트 66쌍·논문 103쌍을 전수 대조해 귀속이 맞는
630건만 승격했다. tier1 1,957 → 3,430.

그 뒤 마지막 남은 빈 물성 키(`interface.surface_energy`)를 접촉각 논문으로 열어
**105/105 달성**. 그래프로만 있던 것(Tatsuta SE), 문서를 못 열었던 것(ACF 벌크물성),
쿼터로 끊겼던 것(본딩와이어·표면처리·이미지센서)까지 회수했다.

### 8단계 — 추정값 몰아내기 (`29ecf57` ~ `9f46774`)

"근거 있는 값이 하나도 없는 재료"를 0으로 만드는 것이 목표였다. 84종 → **0종**.
네 갈래로 나눠 동시에 밀었다.

**(a) 노트에 갇힌 값 구조화 (74건)** — 박리력·차폐효과·열저항은 taxonomy에 대응 키가 없어
그동안 `notes` 문자열로만 보존돼 있었다. 조회·비교·DYNA 출력 어디에도 안 잡히는 죽은
데이터였다. `interface` 도메인을 신설하고 12키를 추가(91 → 103)해 SI 환산 후 정식 등록.

**(b) 표준 합금 (341건)** — SUS·Al·Ti·강·황동·Mg·W 30종은 애초에 규격·공인 DB에 값이
있는데도 계열 추정만 달려 있었다. ASTM/JIS 최소보증치는 tier2(standard), AZoM·MakeItFrom은
tier3(database)로 **구분해** 등록. 실측이 아니므로 tier1은 쓰지 않았다.

**(c) 벤더 우회 확보 (137건)** — "TDS가 로그인 뒤에 있다"고 포기했던 것들. 대부분
**포기가 이르렀다**. Corning은 UA+Referer로 403이 뚫렸고, Dexerials ACF는 TDS가 아니라
제품 페이지에 도전입자경·본딩 조건이 있었으며, 3M OCA 점탄성은 TDS가 아니라 폴더블
백서 Table 1과 논문에 있었다. Envalior는 CAMPUS 출력물을 재배포하는 대리점 PDF로.

**(d) 논문·제품지정·디지타이즈 (493건)** — 벤더 문서가 존재하지 않는 부류(OLED 유기층·
포토레지스트·박막)는 논문으로, 부류 이름뿐이던 재료 19종("OCA UV Cured" 등)은 실제 상용
제품을 지정해서, 그래프로만 공개된 것(Tatsuta 차폐효과)은 `digitize_curve.py`로.

## 정한 규칙 (다시 할 때도 지킬 것)

1. **지어내지 않는다.** 문서·논문에 실제 있는 수치만. 빈 게 틀린 것보다 낫다.
2. **등급을 정직하게.** 다만 tier의 실제 기준은 "문서의 종류"가 아니라 **"값의 성격"** 이다.
   - **tier1** — 특정 제품·시편에 대해 **문서에 인쇄된 실제 시험값**.
     벤더 TDS든 논문이든 상관없다(현재 tier1 1,957건 중 1,662건이 벤더 TDS 유래).
   - **tier2** — 핸드북·규격 최소보증치·공인 DB.
   - **tier3** — 계열/클래스 대표값, 2차 인용, 좌표 추출값.
   - **tier4** — 계산·유도·추정.
   계열 대표값에는 "정밀 설계 시 업체 데이터시트로 대체 권장" 노트를 단다.

   `method`는 **measured / handbook / computed / estimated** 넷만 쓴다.
   `datasheet`는 방법이 아니라 출처 종류다(한때 method로 쓰여 902건이 섞여 있었다).

   정리 후 method×tier는 아래 조합만 남는다 — 다른 조합이 나오면 어딘가 어긋난 것이다.
   | method | tier | 뜻 |
   |---|---|---|
   | measured | 1 | 문서에 인쇄된 그 재료의 시험값 |
   | measured | 3 | 다른 시료를 측정한 클래스 대표값 |
   | handbook | 2 | 핸드북·규격 최소보증치 |
   | handbook | 3 | 2차 DB(AZoM 등), 논문이 인용한 문헌값 |
   | computed | 3 | 그래프 디지타이즈(원 데이터는 실측, 좌표 오차만 얹힘) |
   | computed | 4 | 유도·시뮬레이션 |
   | estimated | 4 | 계열·등가근사 |

   판정은 `scripts/catalog/normalize_tiers.py`가 노트·조건의 표지로 자동 분류하고,
   애매한 것만 스크립트 안 `MANUAL` 목록으로 개별 판정한다(재현 가능하게 남길 것).
3. **조건 없는 값은 의미가 없다** — 아래는 조건 없으면 기록 금지.
   - Dk/Df → 주파수
   - 이방성 물성(방열 시트·PGS·결정) → 방향/결정방위
   - 소광계수·분광방사율 → 파장
   - 크리프율 → 응력·온도
   - 확산계수 → 확산종·온도
   - 박막·소결재 → 두께·어닐·기공률 (없으면 벌크값과 구분 불가)
4. **범위값은 중간값을 만들지 않는다.** 하한만 쓰거나 min/max로 분리.
5. **단위는 SI로.** 특히 비율 물성(연신율·흡습률)을 퍼센트로 넣으면 100배 오류.
6. **유도값은 실측으로 위장하지 않는다.** SAC305 크리프율은 Norton 상수에서 계산한
   값이라 tier4·`method=computed`로 낮추고 유도 과정을 노트에 남겼다.

## 실제로 잡은 데이터 오류 (같은 함정 재발 방지)

| 오류 | 실체 | 영향 |
|---|---|---|

**dedupe의 함정** — 세 번 물렸다.
1. 조건 표기만 다른 같은 값은 병합해야 하지만 `Isola Dk 3.92 @5GHz`와 `@10GHz`는 별개
   측정이다. **정규화 조건이 다르면 병합하지 않는다.**
2. 그런데 조건이 `A/A/B`로 섞인 그룹에서 정보량 최고인 `B`를 keeper로 잡으면
   진짜 중복인 `A·A`를 놓친다. **조건 서명별 버킷으로 나눠서** 각각 병합해야 한다.
3. 이방성 방향 표기가 `axis`/`direction`으로, 값도 `in-plane`/`in-plane (X,Y)`로 갈린다.
   키와 값 양쪽을 정규화해야 같은 측정으로 인식된다.

**인제스트 검증기의 함정**: "기존 tier1 실측을 덮지 않는다"는 규칙이 **조건이 다른 별개
측정까지 막았다.** 조건 서명이 일치할 때만 차단하도록 고쳤다. 신규 키에는 물리 범위를
걸어두면 범위 자체가 단위 검산이 된다 — DOL을 µm 원값으로, CS를 MPa 원값으로,
TCR을 ppm/K 원값으로 넣으면 등록 단계에서 걸린다.

**적재가 멱등이라 측정이 조용히 사라진다**: `upsert_property_value`는
(재료·물성·출처·조건)에 멱등이다. 조건이 같고 값만 다르면 나중 것이 앞의 것을 **덮는다**.
3M Viscoelastic 112P05 박리력이 112P02와 시험조건이 같아 이렇게 사라져 있었다 —
그레이드가 `conditions`가 아니라 `note`에만 있었기 때문이다.
**한 제품군의 여러 그레이드를 한 재료에 담을 때는 `grade`를 반드시 conditions에 넣어라.**
지금은 인제스트가 충돌을 감지해 덮어쓰기 대신 거부하고 사유를 보고한다.

```
에이전트 (WebSearch → extract_datasheet.py → JSON)
   ↓  DB 직접 쓰기 금지
ingest_agent_json.py  ← 6단계 검증

   ② 단위가 정의와 일치하는가
   ③ 출처(url/doi/title)가 있는가        ← 없으면 거부
   ④ 물리적 범위 내인가                  ← 밀도·PR·연신율 등 28개 키
   ⑤ 비율 물성이 1을 넘지 않는가          ← 퍼센트 오입력 차단
   ⑥ 기존 tier1 실측을 덮지 않는가        ← 단, 조건이 다르면 별개 측정이므로 통과
   ↓  --apply
라이브 DB → merge_sources.py → dedupe_values.py → 백업
```

실제 에이전트 출력에서 드러나 방어 처리한 형식 편차: 문자값(UL94 `"V-0"`),
`value_text` 별도 필드, `source.kind: "paper"`(DB 제약 밖), `category: "세라믹"`,
`new_material`이 dict 아닌 문자열, 이중 인코딩된 `conditions`.

**에이전트에게 키 이름을 불러줄 때는 DB에서 확인시켜라.** 그럴싸하지만 없는 키를
지어낸다 — `thermal.glass_transition_temp`(실제는 `thermal.glass_transition`),
`thermal.expansion_coefficient`(→ `expansion_linear`), `mechanical.poissons_ratio`
(→ `poisson_ratio`), `electrical.resistivity`(→ `resistivity_volume`).

**병렬 수집 시 산출 파일을 반드시 확인하라.** 에이전트가 하위 에이전트를 낳고 결과를
병합하지 않은 채 끝나는 경우가 있다. 재료명·키·값으로 DB와 대조해 회수해야
50건이 조용히 사라지지 않는다. 여러 세션이 같은 스크래치패드를 쓰면 남의 파일을
병합 대상에 넣지 않도록 파일명을 명시적으로 고정할 것.

## 19. 온도가 '값'인 물성에 온도를 '조건'으로 달지 말 것 (2026-08-03)

노트에 °C가 보인다고 온도 조건으로 구조화하면 안 되는 물성이 있다. 융점·Tg·최대사용온도·HDT는
**값 자체가 온도**라서, 노트의 °C는 조건이 아니라 값의 재기술이다. 이걸 조건에 넣으면
대표값 선택(`_rep_rank`의 상온 근접 규칙)이 무너진다 — 텅스텐 융점 3410 °C가 상온에서 3387 °C
떨어진 값으로 계산돼 맨 뒤로 밀린다.

실제로 이번에 48건을 잘못 넣었다가 전량 되돌렸다. 되돌리는 판정은 "조건 온도가 값 자신과 같은가"로 했고,
같지 않은 2건(SAC305 #968, CCL #1103)은 노트의 다른 수치를 잘못 집어온 경우라 따로 고쳤다.
융점에 `temperature_C: 23`이 찍힌 17건도 함께 제거했다.

온도가 진짜 조건인 물성은 전도도·열저항·비열·팽창계수·확산도처럼 **값이 온도가 아닌** 것들뿐이다.

## 20. 벤더 표의 '면적당 투과량'은 투과계수가 아니다 (2026-08-03)

UPILEX-25S 데이터시트 Table 4-1은 산소 `0.8 ml/m²`(30 °C, 1 bar, 24 h, ASTM D1434)로 적는다.
이건 면적당 투과량이지 `mol/(m·s·Pa)` 투과계수가 아니다. DB에는 원값이 환산 없이 들어가 있어
Kapton HN(4.9e-17)보다 14자리 큰 0.0008이 저장돼 있었다.

    P = (투과량[mL] / 22414) / 86400 × 두께[m] ÷ Δp[Pa]

이 식을 Kapton HN의 25 cc/(100 in²·24 h·atm)에 적용하면 DB 기존값 4.906e-17이 0.63% 오차로
재현된다 — 식이 맞다는 검산을 먼저 하고 나서 Upilex를 고쳤다(O2 1.033e-19, CO2 1.549e-19).
결과 계수가 Kapton보다 475배 낮은 점은 UBE 측정하한 가능성과 함께 노트에 남겼다.

**같은 결함을 일괄로 찾는 법.** 물성키별 log10 중앙값에서 3자리 이상 떨어진 값을 훑으면 된다.
131건이 걸렸고 대부분은 진짜 그런 물성이었다(연질폼 인장강도 83 kPa, Prony 완화시간 1e-16 s,
Ogden μ1이 작고 α1이 큰 stiffening 항). 진짜 결함은 지르코니아 파괴인성 1건(6 → 6.0e6 Pa·m^0.5)뿐이었다.

## 21. 해석 준비도 — 무엇이 되고 무엇이 막히는가 (2026-08-03)

`scripts/catalog/analysis_readiness.py`로 해석 6종의 재료별 완결률을 센다. 물성 총량이 아니라

| 해석 | 대상 | 필수 완비 | 선택군까지 |
|---|---|---|---|
| 구조 | 425 | 241 (56%) | 208 (48%) |
| 열전달 | 425 | 245 (57%) | — |
| 열응력 | 425 | 239 (56%) | — |
| 결로(투습) | 309 | 131 (42%) | 102 (33%) |
| 벤딩 | 169 | 77 (45%) | **9 (5%)** |
| 낙하 | 425 | 88 (20%) | **0 (0%)** |

**낙하가 0%다.** 율속 데이터(Cowper-Symonds C·p 또는 DIF)가 폼 3종에만 있고 금속 63종 전부 없다.
DYNA 덱은 이미 이걸 알고 c/p 자리에 0을 쓰면서 경고 주석을 남긴다. 낙하는 10²~10³/s 영역이라
율속이 없으면 항복강도를 크게 과소평가한다.

**벤딩 5%.** 폴더블 복원·접힘자국은 점탄성(Prony)이 있어야 보는데 OCA 9종뿐이다.

**포아송비 172종 누락이 교차 병목**이다 — 구조·벤딩·낙하·열응력을 동시에 막는다.
E·G가 둘 다 있어 ν=E/(2G)-1로 회수되는 건 2종뿐이고 170종(폴리머 97·복합 30·고무 22·폼 21)은
새로 수집해야 한다. 밀도 누락 50종(라미네이트 18 포함)은 동해석 전부를 막는다.

**척도를 만들 때 대상 범위를 먼저 정할 것.** 처음엔 벌크 금속에도 층두께를 요구해 벤딩을 8%로,
금속·세라믹에도 투습도를 요구해 결로를 4%로 잘못 셌다. 금속은 흡습하지 않고 벌크재에 층두께는
의미가 없다 — 범위를 좁히니 각각 45%, 33%가 됐다. 없는 결함을 만들어내는 지표는 지표가 아니다.

**수집 시 주의(이번에 버린 것).** Škrlec & Klemenc 2016(sv-jme, DOI 10.5545/sv-jme.2015.3266)의
C-S 계수는 시편이 "mild-steel sheet metal"로 등급 미상이고 C 단위가 `ms⁻¹`로 모호해 기록하지 않았다.
DB 재료명(SPCC/S45C/SCM440)과 매칭되지 않는 값은 넣지 않는다.

## 22. 낙하 해금 — 주요 구조금속 율속 확보 (2026-08-04)

Cowper-Symonds C·p를 4종에 넣었다. DYNA 덱의 "변형률속도 항 없음" 경고가 사라지고 c/p 필드가 찬다.

| 재료 | C (1/s) | p | 원출처 |
|---|---|---|---|
| SPCC 연강 | 40.4 | 5 | Cowper and Symonds |
| Al6061-T6 | 6500 | 4 | Bodner and Symonds |
| SUS304 어닐 | 100 | 10 | Forrestal and Sagartz |
| Ti Grade 2 | 120 | 9 | Symonds and Chon |

**단위를 표에서 확정한 뒤에 넣었다.** MDPI 직접 접근이 403이라 Europe PMC 미러
(`https://www.ebi.ac.uk/europepmc/webservices/rest/PMC9181996/fullTextXML`)로 Wang et al.
Materials 2022, 15, 3880 Table 6을 열었다. 헤더가 `Material | C/s−1 | P | literature`로
**단위가 표에 인쇄돼 있다.** 이게 없으면 넣지 않는다 — C가 `ms⁻¹`인 논문이 실제로 있다.

**Ti는 등가 확인 후 추가했다.** 표기가 "α-titanium (Ti50A)"인데 DB 재료는 Ti_Grade2다.
Ti-50A = TIMETAL 50A = ASTM Grade 2 = UNS R50400 등가를 MatWeb 데이터시트 제목
"TIMET TIMETAL 50A CP Titanium (ASTM Grade 2)"과 AZoM "Grade 2 Unalloyed Ti (Pure) 50A
(UNS R50400)"로 교차 확인했다.

**모델이 부적합해 버린 것.** Al5083-H116은 1e-4~1 s⁻¹에서 동적변형시효로 **음의 변형률속도
민감도**를 보인다. Cowper-Symonds는 음의 민감도를 표현할 수 없으므로 C/p 자체가 성립하지 않는다.

**DIF 0건인 이유.** 숫자로 인쇄된 DIF는 거의 전부 콘크리트·철근이다. 금속 논문은 속도별
항복강도를 표로 주지만 σd/σs는 인쇄하지 않아, 채우려면 나눗셈이 필요하다 — 역산 금지 규칙에 걸린다.

## 27. SQLAlchemy JSON 컬럼의 None이 문자열 'null'이 된다 (2026-08-04)

정합성 검사의 "조건이 dict 아님"에 7건이 걸렸는데 값이 전부 문자열 `'null'` 이었다.
원인은 스키마다 — `mapped_column(JSON)` 은 파이썬 `None` 을 SQL NULL이 아니라 **JSON 'null'**로
직렬화한다. `ingest_agent_json.py` 의 `conditions=cond or None` 이 그대로 걸렸고,
MCP `register_property` 경로도 같은 버그를 공유했다.

    conditions: Mapped[dict | None] = mapped_column(JSON(none_as_null=True), nullable=True)

`none_as_null=True` 하나로 두 경로가 동시에 고쳐진다. 회귀 테스트를 붙였다
(`test_conditions_none_stored_as_sql_null`).

## 29. 시험법이 측정 방향을 규정한다 (2026-08-04)

교차검증도 했다. Taconic 자료집 표의 TLY-5(0.22)·RF-35(0.24)가 각 단독 TDS 값과 정확히

## 32. 티어 자동 정규화가 오분류한 사례 — 논문 제목의 "Simulation" (2026-08-04)

Cowper-Symonds C/p 6건이 `normalize_tiers.py` 재실행에서 **computed/tier4로 오강등**됐다.
원인은 출처 제목이 "Numerical Simulation Study on Factors Influencing…"이라 COMPUTATIONAL
정규식에 걸린 것이다. 하지만 이 값들은 그 논문이 **계산해 낸 값이 아니라** Cowper&Symonds ·

**교훈.** 자동 티어 규칙은 "문서 종류"를 보지만 tier가 뜻하는 건 "값의 성격"이다.
둘이 어긋나는 경우가 반드시 생기므로 예외 목록이 필요하고, 예외를 넣은 뒤에는
**재실행해서 실제로 보호되는지 확인**해야 한다.

## 33. 포아송비를 '가정값'으로 채우다 — 166 → 2종 (2026-08-04)

포아송비 누락이 구조·벤딩·낙하·열응력을 동시에 막는데 수집으로는 풀리지 않는다
(ISO 10350-1 / CAMPUS 항목 체계에 포아송비가 없다, BLOCKED_SOURCES I장).
사용자 결정에 따라 가정값을 넣되, **가정임을 데이터에 새겨** 실측과 섞이지 않게 했다.
스크립트는 `scripts/catalog/fill_assumed_poisson.py`.

**원칙 네 가지.**
1. 가정의 근거는 **카탈로그 안의 실측값**이거나 **DB에 이미 인용된 문헌**이어야 한다.
   외부에서 기억으로 가져오지 않는다.
2. `tier4 · method='estimated' · conditions.assumption=true`로 새긴다. 대표값 선택에서
   실측에 항상 밀리고, 실측이 들어오면 자동 대체된다.
3. 클래스가 균질할 때만 건다 — 실측 4건 이상 & IQR ≤ 0.07, 또는 산포가 극히 좁으면(IQR ≤ 0.02)
   3건도 허용. 이건 클래스 대표값 규율(BLOCKED_SOURCES J장)과 같은 기준이다.
4. 고무·점착층에 ν=0.5를 쓰지 않는다 — 체적잠김으로 해석이 터진다.

| 클래스 | ν | 근거 | 적용 |
|---|---|---|---|
| 직물유리 적층판 | 0.183 | 카탈로그 실측 34건 중앙값, IQR 0.042, 면내(ν12) | 20종 |
| 금속 | 0.330 | 실측 66건 중앙값, IQR 0.053 | 6종 |
| PI 필름 | 0.340 | 실측 3건이 전부 0.340 (IQR 0) | 7종 |
| 무충전 수지 | 0.380 | 실측 9건 중앙값, IQR 0.035 | 13종 |
| 유리충전 수지 | 0.400 | 실측 4건 중앙값 | 19종 |

## 34. 대표값 순위의 실제 사고 — SAC305 영률이 4배 틀린 채 카드에 실렸다 (2026-08-04)

솔더볼 고속 충격 해석 문의를 받고 SAC305 DYNA 카드를 뽑아 보니 이렇게 나왔다.

    $   E   6900 MPa   <- [1] Indium Corporation

SAC305 영률이 6.9 GPa다. 상온 인장 측정값 27.83 GPa가 DB에 **있는데도** 밀렸다.

**원인은 `_temp_distance`가 온도 무표기를 '상온 거리 0'으로 처리한 것이다.**
27.83 GPa 행은 `temperature_C: 25`라 거리 2, 6.9 GPa 행은 조건이 없어 거리 0 — 무표기가 이겼다.
온도를 밝히지 않은 값이 상온이라고 명시한 측정값을 이기는 건 앞뒤가 안 맞는다.

무표기에 `_UNSPECIFIED_TEMP_PENALTY = 5.0` °C를 매겼다. 상온 명시값(|ΔT| 몇 도)보다는 뒤,
고온·저온값보다는 앞이다. 기존 규칙("무표기가 200 °C 값보다 우선")도 그대로 지켜진다.
**이 하나로 103건의 대표값이 바뀌었다.** 은 도전성 에폭시 체적저항 1e-7 → 4e-6 Ω·m 처럼
명백히 개선된 것들이다(은 에폭시는 4e-6 수준이지 1e-7은 순금속 급이다).

## 35. 물성마다 '지배 조건'이 다르다 — 광학은 온도가 아니라 파장 (2026-08-04)

34의 수정 영향을 훑다가 c-Si 소광계수가 24배 뒤집힌 걸 발견했다. 원인이 다르다 —
**광학 물성의 지배 조건은 파장인데 순위 함수가 온도만 봤다.** 실리콘 k는

    400 nm 0.387 · 550 nm 0.028 · 620 nm 0.022 · 1000 nm 0.0005    (800배)

온도 기준으로 고르면 어느 파장이 뽑힐지 알 수 없다. `_rep_rank`가 `optical.*` 키에 대해
**나트륨 D선 589.3 nm**(굴절률 n_d와 아베수의 정의 파장)에 가까운 값을 고르게 했다.
적용 후 c-Si는 620 nm, 사파이어는 589.3 nm 행이 대표가 된다.

**교훈.** 대표값 순위는 "조건이 적은 것"이 아니라 "**그 물성의 정의 조건에 가까운 것**"이어야 한다.
온도·파장 다음으로는 이방성 재료의 방향이 후보다.

## 36. 점소성 물성키 9종 신설 — 솔더 고속 충격 (2026-08-04)

솔더는 상온이 이미 **T/Tm ≈ 0.61**(SAC305 융점 490 K)이라 항상 크리프 영역에 있다.
정적 항복강도 22 MPa만으로 10²~10³/s 낙하를 풀면 소성변형이 폭주해 요소가 뒤집힌다.

그런데 카탈로그에 점소성 상수를 담을 **키 자체가 없었다.** Cowper-Symonds C/p 외에는
Johnson-Cook도 Anand도 자리가 없고, SAC305의 Norton 크리프 상수는 노트 텍스트에만 있어
카드로 나갈 수 없었다. 아래 9종을 신설했다(정의 119 → 128).

    johnson_cook_a/b/n/c/m · anand_constant · norton_coefficient/exponent · yield_strength_at_rate

**Prony·초탄성과 같은 규율을 건다.** `conditions.model`과 `conditions.term`이 없으면 세트를
복원할 수 없다. Anand는 9상수(s0, Q/R, A, ξ, m, h0, ŝ, n, a)가 한 세트라 일부만 있으면 못 쓴다.
JC는 **C(율속항)가 없으면 Johnson-Cook이 아니다** — 예전에 우리 DB에 "Johnson-Cook"이라
적혀 있던 것이 실은 Ludwik 식 A+B·εp^n 이었다(C도 m도 없었다).

`yield_strength_at_rate`는 LS-DYNA LCSR(변형률속도 스케일 곡선)의 원자료다.
논문이 여러 속도의 응력-변형 곡선을 표로 주면 각 속도의 항복강도를 개별 행으로 담는다.

## 37. 솔더 점소성 수집·LCSR 곡선 자동 생성 (2026-08-04)

**Johnson-Cook 완성 세트 1개**를 확보했다. Qin Fei 외, 力学学报 42(3) 439-447 (2010),
doi 10.6052/0459-1879-2010-3-2008-680. 表4의 Sn3.0Ag0.5Cu 행.

    A = 38 MPa · B = 275 MPa · n = 0.71 · C = 0.0713 · Tm = 490 K
    σ = [A + B(εᵖ)ⁿ](1 + C·ln ε̇*)(1 − T*ᵐ),  ε̇* = ε̇/ε̇₀,  ε̇₀ = 0.001 /s
    SHPB/SHTB 600~2200 /s

스캔 PDF라 300 dpi로 렌더링해 표를 판독했고, **A=38 MPa가 같은 논문 表1의 준정적 항복강도
38 MPa와 정확히 일치**해 물리 검산을 통과했다.

**m=1.0은 측정값이 아니다.** 원문이 "由于没有进行不同温度下的实验… 根据大多数金属材料的值给出"
(온도 실험을 하지 않아 대부분 금속의 통상값을 차용)이라 밝힌다. 그런데 등록기가 `method="assumed"`를
어휘에 없다고 `measured`로 바꿔 버렸다 — 논문이 "측정하지 않았다"고 명시한 값이 실측으로 둔갑했다.
`METHOD_MAP`에 `assumed→estimated`, `fitted/fit/inverse→computed`를 넣고 해당 행을 tier4로 내렸다.

**물리적으로 의심스러운 세트를 tier3으로 내렸다.** CMC 40(3) 165-178 (2014)의 GA 역해석
A=145.5 MPa는 SAC305 정적 항복(20~40 MPa)의 4~7배다. 열 귀속은 원문에서 확인해 표기 오류가
아니라 볼전단 역해석 결과 그 자체였다. tier1로 두면 Qin의 완성 세트를 대표값에서 밀어내므로
computed·tier3으로 내리고 "카드로 내보내지 말 것"을 note에 박았다.

**Anand 9상수 완성 세트 5개.** 그중 Zhang 2018(Auburn PhD) Pristine 세트가 25~200 °C,
10~75 /s로 낙하 영역에 가장 가깝다. 일부만 있는 세트는 전량 버렸다 — 9상수가 한 세트라
반쪽으로는 카드가 안 된다.

### LCSR 곡선을 카드에 물렸다 (`rate_scale_points`)

`yield_strength_at_rate` 실측점을 그대로 **변형률속도 → 항복응력 배율** 곡선으로 만들어
`*DEFINE_CURVE`로 내보내고 `*MAT_024`의 LCSR 필드에 연결한다. Cowper-Symonds 2상수 근사에
끼워 맞출 필요가 없다.

**온도가 섞인 점은 쓰지 않는다.** 율속 효과와 온도 효과가 뒤엉키기 때문에 온도가 같은
(또는 둘 다 미표기인) 계열만 쓰고 상온 계열을 우선한다.

**여기서 실제 함정이 하나 나왔다.** 처음 만든 곡선은 기준(1.0배)이 Qin의 준정적 38 MPa인데
카드의 SIGY는 다른 출처(Indium)의 22 MPa였다. 그대로 쓰면 1800 /s에서
22 × 2.289 = **50 MPa**가 나온다 — 실측은 87 MPa다. 1.7배 과소평가다.
LCSR을 쓸 때는 **SIGY를 곡선의 기준값으로 바꾸고** 그 사실을 카드 주석에 남기게 했다.

    $   ※ SIGY를 22 → 38 MPa로 바꿔 씁니다 — LCSR 배율의 기준(1.0배)이 율속 시험의
        준정적 항복강도라, 다른 출처의 SIGY를 그대로 두면 고율속 응력이 어긋납니다.

**배율 곡선을 쓸 때는 기준값의 출처가 같아야 한다.** 물성별로 최적 출처를 고르는 대표값
규칙과 정면으로 충돌하는 지점이라, 카드 생성 단계에서 따로 맞춰 줘야 한다.

### 못 채운 것
Norton 크리프 A·n 0건 — 오픈액세스 범위에서 벌크 SAC305의 A를 **단위와 함께** 인쇄한 문헌이
없었다. Schubert 계열 double-power-law는 Elsevier/IEEE라 막혀 있다. 역산은 하지 않았다.
JC 세트도 1개뿐이다(SHPB 기반 SAC305 논문은 대부분 유료).

## 41. 흡습 수집 — EMC가 1·2·3 고리를 갖췄다, 4번은 여전히 0 (2026-08-05)

### 내 지시서가 틀렸고 에이전트가 잡았다

브리핑에 "EMC의 Csat는 수~수십 mol/m³"라고 적었는데 **한 자릿수 낮았다.**
실제 인쇄값은 EMC 200~310, PI 650~1420 mol/m³다. 검산하면

    EMC   220.2 mol/m³ × 0.018015 / 1900 = 0.21 wt%   (문헌 0.2~0.5 wt%)
    Kapton 1418.8 mol/m³ × 0.018015 / 1420 = 1.80 wt% (문헌 ~1.8 wt%)

정리해야 하지만, 지금은 조회 코드가 둘 다 읽으므로 급하지 않다.)

## 42. 솔더 열피로 — 로드맵 1순위 확보 (2026-08-05)

Anand로 사이클당 소성일 ΔW까지 가고 **사이클 수로 환산을 못 하던** 고리가 채워졌다.

**Coffin-Manson 완성 쌍 9개** (전부 SAC305 직접 시험, tier1, 상온)
Wei 2022(Auburn 박사) 4쌍 — 표면처리 OSP/ENIG × 제어방식.
Abueed 2020(Auburn 박사) 5쌍 — dwell 0/10/60/180 s + global.
계수 0.108~0.815, 지수 −0.396~−0.745.

**Darveaux 완성 세트 1개** (Motalab 2013, Auburn 박사, 무시효 행)
K1 = 37.97 `Cycles/MPa^K2` · K2 = −2.80 (tier1 measured)
K3 = 3.99e−6 `m/Cycles-MPa^K4` · K4 = 2.05 — **원문이 "K4를 가정하고 K3를 계산했다"고
밝혀 tier4·estimated로 내렸다.**

에이전트가 수치 검산까지 했다 — ΔW≈0.25 MPa에서 Ni≈1.8e3, da/dN≈2.4e−7 m/cycle
(원문 실측 1.94e−7과 동차수), Nf≈4.2e3으로 원문 Fig.5.9 무시효 특성수명(4~5천)과 일치.

### 표준형이 아니라는 표기가 결정적이었다

등록된 9쌍은 **교과서 Coffin-Manson(Δεp/2 = εf'(2Nf)^c)이 아니다.**

    Wei    : dEps_p   = delta * N^(-alpha)     (전범위 소성변형률 vs 특성수명)
    Abueed : dGamma_p = C * N63^(-m)           (전범위 소성**전단**변형률 vs Weibull N63)

반진폭이 아니라 전범위, 2Nf가 아니라 N이다. **표준 구현에 그대로 넣으면 변형률과 사이클
양쪽에서 2배씩 틀린다.** 게다가 Wei는 수직변형률, Abueed는 전단변형률이라 서로 섞어도 안 된다.
`conditions.model_form`에 원문 식을 verbatim으로 박아 두 형태를 구분했다.

원문이 지수를 양수 α로 인쇄하고 식이 `N^(-alpha)`이므로 부호를 붙여 `c = -α`로 등록했고
그 사실도 note에 적었다.

### 에이전트가 버린 것 — 등급 위장이 두 건

- **εf' = 0.325** — 본문이 "the fatigue ductility coefficient εf = 0.325 was used for
  **a eutectic tin-lead solder**"라고 자백한다. SAC305 열에 실려 있었지만 SnPb 값이다.
- **Darveaux K1=71000/56300/48300 계열** (Micromachines 15(4):428) — 본문이 "eutectic
  solder"라 설명하고 동일 논문의 Anand 상수가 62Sn36Pb2Ag다. 게다가 **K3의 지수부(×10⁻⁷)가
  XML 원문에서 누락**돼 있었다(단위 역산으로 확인). 2차 인용이기도 하다.
- **Abueed Table 7.5 / Sci Rep Table 5**(온도별) — **같은 학위논문 Table 6.2와 동일
  명목조건에서 0.108/0.565 vs 2.528/0.859로 20배 불일치.** 폐기.

### 못 채운 것
**온도 의존성이 비어 있다.** 등록된 9쌍이 전부 상온이다. 솔더는 T/Tm이 높아 εf'·c의 온도

## 43. Morrow 에너지 모델 30쌍 — 온도 의존성이 채워졌다 (2026-08-05)

### 결정적 함정 — 계수의 단위가 두 계열로 갈린다

같은 Morrow 상수인데 W가 **에너지(J)** 계열과 **에너지밀도(MPa)** 계열로 나뉜다.
**FEA에서 뽑은 ΔW(에너지밀도)를 Auburn 계열 상수(에너지)에 넣으면 4자릿수 틀어진다.**

- Auburn 계열(Wei·Abueed·Sci Rep) — Wei 원문 Eq.5-4가 `W (J)`로 명시하고 Fig.5-11 축이 `Work (J)`
- Mustafa/Materials 17 — FEA 에너지밀도(MPa). ΔWp = 4.504·N^(−0.3906)이 N=1000에서 0.303 MPa로
  동일 SAC305 PBGA의 Motalab 실측 ΔW(0.25~0.40 MPa)와 일치

`conditions.unit_of_term`에 시험체 규모까지 적었다(`9-joint sandwich` vs `개별 조인트 1개`).

**에이전트의 논거를 재검산해 약화시켰다.** 에이전트는 "Wei가 Abueed보다 9~10배 커서
9조인트 시험체 = 에너지(J)"라고 논증했는데, 조건을 맞춰 다시 재니 배수가
**4.8배(Abueed T7.4 대비) ~ 12.7배(T6.3 대비)** 로 갈린다. Abueed 자신의 두 표가 3배
어긋나므로 **배수로 조인트 수를 특정하긴 어렵다.** J 귀속의 실제 근거는 Wei 원문의 표기이고,
Abueed·Sci Rep은 같은 연구실·같은 시험체 계열이라는 **정황 추론**이다. 26건에 이 사실을 부기했다.

provided by 3M Company"라고 밝혀 이미 404를 280에 병합한 바 있다. 430도 같은 건이라
**병합**했다(중복 37건 삭제, 이관 1건).

### 가드를 넓혔다 — 마스터커브 완화시간

`prony_relaxation_time` 상한 1e12 s에 1e14 s가 걸렸다. **1e14 s ≈ 3백만 년**이라 물리적으로는
황당하지만, 마스터커브는 실측 창(수 시간)을 시간·온도 등가로 수십 자릿수 확장한 **피팅
파라미터**다. 하한을 1e-20으로 넓힌 것과 같은 이유로 상한을 1e16으로 올렸다.

### 브리핑 전제가 틀렸던 것

내가 "앞 배치에서 버렸다"고 적은 논문 3편(PMC8879156·PMC12348320·PMC13284314)이
**이미 DB에 등록돼 있었다**(material 282·390·386). 앞 배치가 0건이었던 건 그것들이
그 이전에 이미 소화됐기 때문이다. 브리핑에 "이미 등록됨"과 "버림"을 구분해 적어야 한다.

## 45. 마찰계수·압축영구변형 (2026-08-05)

마찰계수 11건 · 압축영구변형 9건.

**PORON 계열이 규칙에 걸려 전량 버려질 뻔했다.** TDS에 `ASTM D3574 Test D @ 70°C`만 찍혀 있고
변형률·시간이 없었는데, 에이전트가 **Rogers 자사 블로그가 시험 파라미터를 인쇄한 것**을 찾아
해결했다(`50% 압축 / 22시간 ± 30분 / 70 °C`). 각 note에 출처를 명기했다.
PORON 값은 전부 **"% max" 규격 상한**이지 대표값이 아니라는 점도 적었다.

**금속 마찰계수는 전량 손대지 않았다** — 표면 상태 불명이라 접촉각 작업 때와 같은 사유다.
TiN 코팅은 인쇄값이 있었으나 `하중 1 N인데 마찰력을 0.9 N`이라 적어 **검산이 안 맞아** 폐기.

## 46. 모드 II 응집영역 0 → 10건, 그리고 흡습 열화 시리즈 (2026-08-05)

**EMC/Cu 리드프레임 4ENF GIIc 196.31 J/m²(건조)** 와 함께 **85 °C/85%RH 흡습 열화 시리즈**가
들어왔다 — 1주 137.1 → 3주 108.89 → 6주 100.43 J/m². 건조 대비 **6주 후 51%**로 떨어진다.

**이건 85/85 사슬의 4번 고리(노화 후 물성 저하)에 해당한다.** `property_retention` 키로는
0건이지만, 계면 파괴에너지의 노화 계열이 같은 정보를 담는다. 흡습 확산(D·Csat·CHE)에 이어
**열화까지 한 재료(EMC)에서 이어진 첫 사례**다.

EMC/Cu 4PB 온도 6점(25→250 °C: 17.78 → 4.71 J/m²)도 확보했다 — **Tg 130 °C를 넘으면 붕괴**한다.

### 에이전트가 외삽값을 거부했다

Kwatra(GT 석사논문)의 GIIC 1739 J/m²는 **ψ≤14° 두 점만으로 Hutchinson–Suo 곡선을 ψ=90°까지
외삽**한 값이다. 논문 스스로 "Additional fracture mechanics tests need to be conducted at
higher mode mixities"라고 적었고, 실측 4ENF 196 J/m²와 **9배** 차이난다. 같은 논문 Table 5.1의
CZ 삼각형 면적(모드 II 715)도 본문값(1739)과 안 맞는다. 전량 폐기가 옳다.

**랩 간 편차도 고지했다** — Cu/EMC가 ψ≈14~15°에서 Tran 17.78 vs Krieger 44.6 vs Kwatra 46.4로
2.5배 차이난다. 단위 오류가 아니라 EMC 배합·리드프레임 표면 차이라, 출처별로 따로 등록하고
note에 상호 참조를 넣었다.

## 47. 배터리 — 가정값이 실측에 밀려난 첫 사례 (2026-08-05)

38건 등록. **분리막 포아송비가 tier4 추정 0.4 → tier2 실측 0.17로 대표값이 바뀌었다.**
포아송비 가정값을 넣을 때 "실측이 들어오면 자동 대체된다"고 설계한 것이 실제로 작동했다.

**MD/TD 이방성 탄성률**도 확보했다(Celgard 2400: MD 955~1282 / TD 485~526 MPa, 하중률 의존).
MD/TD 비가 2.0~2.4배라 등방 가정으로는 못 푼다.

**흑연 복합전극의 상태 의존 탄성률** 0.4 GPa(탈리튬화) → 1.1 GPa(리튬화)도 들어왔다.
저자가 "순수 흑연(약 10 GPa)보다 한 자릿수 작다"고 명시해, 기존 DB의 10 GPa(intrinsic)와
**층 단위 물성이 구분된다.**

### 에이전트 제안대로 스웰링 키 2종을 신설했다 (정의 145 → 147)

"인쇄 형태가 넷으로 갈려 키 하나로는 못 담는다"는 분석이 정확했다.

    A 사이클별 % 팽창 · B SOH별 절대두께 · C 부분몰부피 Ω · D 메커니즘 분류

B는 기존 `layer_thickness` + `state_of_health` 조건으로 충분하고(이미 그렇게 등록됨),
D는 셀 레벨 응답이라 카탈로그 밖이다. A와 C만 키를 만들었다.

**`measure` 축을 필수로 박은 이유** — 문헌이 "volume expansion"이라 쓰면서 실제로는
1D 딜라토미터로 **두께만** 재는 경우가 흔하다. 체적변형률과 두께변형률을 섞으면 3배 틀린다.
부호 규약(팽창 양수, 층상산화물 양극은 고SOC에서 수축하므로 음수 정상)과
**흑연 Ω의 4배 문헌 불일치**(1.47e-6 모델입력 vs 6.5e-6 실측)도 taxonomy 주석에 적었다.

### 에이전트가 버린 것 중 눈여겨볼 것
- **PMC11055120의 파단변형률**은 원문이 "adjusted to the element size"라고 명시한
  **메시 정규화 파손모델 캘리브레이션 파라미터**다. 재료 연신율이 아니다.
- 45°(DD) 방향 물성은 MD/TD가 아니라 폐기.
- "battery grade copper foil" 45 GPa는 **RA/ED 조질 미표기**라 폐기(게다가 벌크 Cu의 절반도
  안 돼 22 µm 박 DMA 컴플라이언스 아티팩트로 의심).
