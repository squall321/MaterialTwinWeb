# 커버리지에서 구조적 부재를 분리한다 — 결정 기록

## 왜 필요한가

7차 파동까지 셀 채움을 **64.5%**로 보고해 왔다. 그런데 544종 중 **124종(22%)**이
저분자 도판트(51종)와 점착테이프(73종)이고, 이 둘은 열물성·기계물성·CTE·젖음이
**구조적으로 발표되지 않는다**는 것을 여러 파동이 각자 확인했다.

두 군을 빼고 재면 **72.7%**다. **지금 8%p는 원리적으로 못 채우는 칸이다.**

100%를 향해 가는 것처럼 보고하면 두 가지가 왜곡된다.
- **남은 일의 크기가 실제보다 커 보인다** — 다음 파동의 목표 설정이 틀어진다.
- **파동의 성과가 실제보다 작아 보인다** — 못 채우는 칸이 분모에 계속 남아 있으니
  아무리 채워도 비율이 더디게 오른다.

## 설계 — 재료 단위가 아니라 (재료군 × 물성) 단위다

"저분자 도판트는 물성이 없다"가 아니다. **광물리 물성은 있다** — 여기수명·양자수율·
몰흡광계수는 논문이 인쇄한다. 없는 것은 밀도·열전도율·비열·CTE·영률·젖음이다.

점착테이프도 마찬가지다. **박리강도·전단유지력·두께는 있다.** 없는 것은 CTE·비열·
항복점·Prony다.

그래서 부재는 **(재료 이름 매처 × 물성 키 집합)** 쌍으로 선언한다.

## 무엇을 부재로 선언할 것인가 — 증거 있는 것만

브리프와 BLOCKED_SOURCES에 **파동을 넘어 반복 확인된 것만** 넣는다. 한 번 못 찾은 것은
부재가 아니다. 각 항목에 어느 파동이 어떻게 확인했는지를 코드 주석에 남긴다.

넣지 않은 것 — "페이월이라 못 받았다"는 부재가 아니라 접근 문제다(FR-4 방향별 열전도율,
EMC 포아송비 등). 이건 언제든 열릴 수 있으므로 분모에 남긴다.

## 지표를 둘 다 보여준다

기존 `셀 채움`은 그대로 두고 **`유효 채움`(구조적 부재를 뺀 분모)**을 나란히 찍는다.
하나만 남기면 "분모를 줄여 숫자를 올렸다"는 인상을 준다. **둘을 나란히 두고 차이를
보이는 것이 정직하다.**

## 위험

**분모를 줄이는 변경이라 숫자가 오른다.** 이력에 반드시 "이 상승은 수집 성과가 아니라
정의 변경"이라고 적는다. 6차 파동의 흡습 키 확대 때와 같은 규율이다.
