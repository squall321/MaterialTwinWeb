## A. 먼저 정해야 할 것 — 지표가 걸려 있는 결정 셋

**셋은 독립이 아니다.** A-1을 정해야 A-2를 반영할 수 있고, A-3은 둘 다에 영향을 준다.

### A-1. 클래스 전이를 반례에서 뺄 것인가 — **규모를 쟀다: 16.2%**

구조적 부재 선언은 **실측(tier≤3) 반례가 하나라도 있으면 자동 은퇴**한다.
tier4는 우리가 만든 가정이라 반례로 치지 않는다 — 8차에 정한 옳은 규칙이다.

**그런데 tier3에 두 종류가 섞여 있다.**

| tier3의 두 얼굴 | 반례 자격 |
|---|---|
| 등급 대체 · 2차 인용 — **어딘가에서 측정된** 값 | 있다 |
| **클래스 대표값 전이** — 한 물질의 값을 재료군에 편 것 | **없어야 한다** |

### 선택지

**(가) `conditions.class_transfer: true` 플래그를 두고 반례 검증에서 제외한다** ← 권장
- 기존 3,505건 소급 표시가 일이다. 다만 **481개 묶음 단위**로 처리하면 되므로 배치 하나면 된다.
- 지표에 `클래스전이 제외 실측기반` 열을 하나 더 낸다. 세 지표가 된다 —

**(나) `method` 를 바로잡는다** — 클래스 전이를 `measured` 로 적는 것이 애초에 부정확하다.
그 재료를 잰 것이 아니다. `handbook` 이 맞다. 무결성 불변식과 함께 봐야 한다.
(가)보다 침습적이지만 **의미가 더 정확해진다.**

**(다) 그대로 둔다** — 부재 판정을 앞으로도 반영할 수 없고, 실측기반 지표가 계속 부풀려진다.

### A-3. 격자 대상 정의 — 19차부터 미룬 것

지금 커버리지 격자는 **카탈로그의 모든 재료**를 해석 대상으로 센다.
그런데 신규 400종 이상이 **시뮬레이션 대상이 아니라 근거 재료**다 —
"SiC 휘스커 30 vol% BAS 유리세라믹"으로 낙하해석을 돌리는 일은 없다.

**(나) `material.attributes` 에 역할을 달고 `scope()` 가 거른다** ← 권장
```json
{"role": "evidence"}   // 논문의 연구용 조성. 계열 근거로 쓰고 해석 대상에서 뺀다
{"role": "product"}    // 실제 시뮬레이션 대상(기본값)
```
- 값은 그대로 남고 계열 근거로 계속 쓰인다.
- **구조적 부재와 다르다** — 부재는 "그 물성이 없다", 이건 "그 해석의 대상이 아니다".
- 분류는 재료명과 출처 종류로 대부분 자동 판별된다(논문 조성명 대 상용 제품명).

**A-1의 (가)를 고르면 이 분류와 같은 배치에서 처리하는 것이 싸다** — 둘 다 재료·행 단위
소급 표시 작업이다.

## E. 권장 순서

**1 — A-1 클래스 전이를 정한다.** 규모(16.2%, 481묶음)를 이미 쟀으므로 결정만 남았다.
이걸 미루면 A-2·A-3이 계속 막히고 파동마다 지표가 더 읽기 어려워진다.

**2 — A-1·A-3을 한 배치로 소급 처리한다.** 둘 다 재료·행 단위 표시 작업이라 같이 하는 것이 싸다.
끝나면 A-2의 113종을 반영하고 N 2종 판정은 폐기한다.

**3 — B-1 벤더 데이터시트 파동.** 91종 + 웹 항목 셋. 코퍼스를 한 번 더 도는 것보다 수율이 높다.

**4 — C-1 대기 키를 한꺼번에 연다.** 값이 이미 확보돼 있어 파동이 필요 없다.
Vogel ΔH를 화학 Ea에 섞지 않는 것만 지키면 된다.

**5 — B-2 재료 신설 + B-3 격자형 표적.** A-3이 끝난 뒤라야 지표를 망치지 않는다.

**6 — B-4 짝 백필.** 값싸고 언제든 끼워 넣을 수 있다.
