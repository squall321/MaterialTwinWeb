## 2. 출처 972 는 열 수 있는 문서를 가리키지 않는다 — 신고

```
source 972 : kind=book
  title      Handbook of Infrared Radiation — emissivity tables (Touloukian TPRC Data Series)
  doi/isbn/url/authors/year/publisher/local_path/content_hash  ← 전부 NULL
  retrieved_at 2026-08-01 15:26:02
```

- **제목 자체가 두 문헌을 한 줄에 붙였다.** `Handbook of Infrared Radiation` 과
  Touloukian *Thermophysical Properties of Matter* TPRC Data Series 는 다른 책이다.
  어느 책의 몇 권 몇 쪽인지 알 수 없고 **식별자가 하나도 없다.**
- §626 의 반대 얼굴이다 — `local_path` 가 비어 있는 것은 흔하지만(76.7%), 여기는
  **doi·isbn·url·저자·연도까지 전부 비어 있어 문서를 특정할 수단이 아예 없다.**
- 그래서 이 201행은 **"핸드북에서 옮겼다" 가 아니라 "핸드북을 근거로 삼겠다고 적었다"** 에 가깝다.
  tier4·`assumption: true` 로 정직하게 표시돼 있으므로 규칙 위반은 아니다. **다만 출처 문자열이
  실제보다 강해 보인다** — 다음 파동이 이 문자열을 보고 "핸드북 값이 이미 있다" 고 읽으면 표적을 놓친다.

| 재료 | 값 | 조건 | 표 |

**검산 — 표 자신의 항등식으로 판독을 닫았다(§603).** Table 3-1 의 권장값 셋이 Table 2-3·2-6 의 원측정 평균과 재현된다.

```
0.15  Polished/Smooth : (0.14 + 0.16 + 0.169 + 0.14 + 0.14) / 5 = 0.749/5 = 0.1498  → 0.15 ✔
0.21  Smooth          : (0.17 + 0.217 + 0.215 + 0.22 + 0.209) / 5 = 1.031/5 = 0.2062 → 0.21 ✔
0.35  Coarse          : (0.35 + 0.39 + 0.325) / 3 = 1.065/3 = 0.355               → 0.35 ✔
```

셋이 다 재현되므로 **열 배정과 표 판독이 동시에 닫힌다.** 그리고 Table 3-1 은 재료 칸에
`SS304/304L` 이라고 **표 자신이 두 등급을 적으므로** 두 등급 모두 원문의 범위 안이다(계열 대입이 아니다).

**둘째 증인** — Table 2-7 의 양극산화 알루미늄 0.82~0.84 가 같은 보고서 Appendix B 의 Figueroa 메모
`Aluminum / Anodized / 29 °C 0.81` 과 0.02~0.03 안에서 만난다. 문서가 다르고 측정 연도가 다르다.

**안 넣은 것** — 같은 절 본문의 `polished Al 6061 0.04 to 0.051` · `sandblasted 0.41` 은
**Touloukian & DeWitt 재인용이고 앞엣것은 구간**이라 안 넣었다(§195 재인용 · §616 구간).
이 칸을 닫으려면 Touloukian & DeWitt 원권을 열어야 한다 — **표적이 그만큼 좁아진 것이 성과다**(§616).

### 5.2 Gilmore Table 4.1 — §602 그대로의 옆 칸 (t2 1행)

`Aluminized Kapton` 블록은 네 행이다.

```
1/2 mil  0.34  0.55   ← 52차에 들어옴
1   mil  0.38  0.67   ← **빠져 있었다. 이번에 넣었다**
2   mil  0.41  0.75   ← 52차에 들어옴
5   mil  0.46  0.86   ← 52차에 들어옴
```

**한 블록 네 행 중 셋을 캐고 하나를 두고 갔다. 그리고 빠진 그 행이 하필 Kapton HN 의 표준 두께(1 mil = 25 µm)다.**
검산 — 블록이 두께에 대해 단조증가한다(0.55 < **0.67** < 0.75 < 0.86). 자리가 맞는다.
같은 시트를 여는 김에 출처 2528 의 `local_path` 도 채웠다(§626 규율 4).

### 5.3 Mikron 편찬표 — 표면상태축을 넣는다 (t3 12행)

| 재료 | 넣은 표면상태 |
|---|---|
| Al1100-O | commercial sheet 100 °C 0.090 · polished 100 °C 0.095 · anodized(chromic acid) 100 °C 0.55 |
| C26000 / C36000 황동 | rolled sheet 20 °C 0.06 · polished 200 °C 0.03 · oxidized 200 °C 0.61 |
| C51000 인청동 | polished 50 °C 0.10 |
| Tungsten_99pct | unoxidized 25 °C 0.024 · 100 °C 0.032 |

- **왜 t3 인가** — 이 표는 등급이 아니라 **원소·계열 단위**로 행을 가른다. 스스로 밝히는 1차 근거는
  CRC Handbook · DMIC Report 177(Battelle) · Thermal Radiation Properties Survey(Honeywell) 셋이다.
  같은 물성에서 이 카탈로그가 Engineers Edge 표를 t3 로 쓴 선례와 같은 자리다.
- **알루미늄 합금 등급에는 안 옮겼다(§586·§123).** 표의 무수식 `Aluminum` 이 가리키는 것은 순알루미늄이고,
  Al1100 은 순도 99.0% 이상이라 같은 물질이다. 6061·5083 같은 합금 등급에 옮기면 우리가 만든 값이 된다.
- **황동 한 재료 안에서 연마면 0.03 과 산화면 0.61 이 20배다.** 기존 t4 0.06 은 조건이 없어
  둘 중 어느 것인지 말하지 않는다 — **이 물성에서 조건 없는 값이 왜 값이 아닌지의 실례다**(§586).
- **겉보기 모순 하나를 갈랐다** — Mikron 의 `Anodized Sheet, Chromic Acid Proc 0.55` 와
  Sandia 의 양극산화 6061/7075/5083 0.82~0.84 는 **모순이 아니라 양극산화 종류·피막두께 차이**다.
  크롬산 양극산화는 피막이 얇다. Siva Kumar 1999(우주용 백색 양극산화, 코퍼스에 있음)가
  verbatim `The emittance of the sample surface increases with the growth of anodic film thickness` 로
  두께 의존을 못박는다. **`양극산화` 라는 낱말 하나로는 값이 정해지지 않는다.**

## 6. 조달 전에 코퍼스를 먼저 쳤다(§626·§635)

- `corpus_index.py search "emissivity"` · `grep -ra` 전권(1,218 적중) 을 먼저 걸었다.
- **코퍼스에서 나온 것** — Nagano 2000(이미 적재됨) · Nagano 2006(같은 연구실 후속인데 **같은 0.22→0.32 결과**라
  §620 대로 안 캤다) · Siva Kumar 1999(초록의 `of the order of 0.80` 뿐이고 값은 Fig.4-6 곡선) ·
  Lee 2017(이미 20행 적재됨) · Fu 2006(이론) · Gogu 2009(`emissivity of 0.8` 가정 — §3 기각) ·
  Finley 1999(저방사 코팅 공정론, 우리 등급 없음).
  **코퍼스는 이 물성에 얇다** — 그래서 조달로 갔다.
- **부재를 확인한 것** — Panasonic PGS 데이터시트 3장(AYA0000 C27·C50·C56)을 받아
  `grep -ic 'emissiv|emittanc'` = **0**. 이 벤더는 PGS 시트에 방사율을 안 찍는다(§127·§613 의 전권 낱말검색).
  **그래서 108/277 을 닫는 유일한 인쇄값은 Nagano 2000 뿐이고, 그것이 이미 277 에 있다.**
- **§601 곁가지가 또 재현됐다** — `optris.com/en/service-support/downloads/emissivity-table/` 가 404 인데
  **404 본문 안에 `/us/en/…` · `/de/en/…` 이 링크로 들어 있었다.**
