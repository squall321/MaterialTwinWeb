# 60차 VD 컨텍스트 노트 — 왜 이렇게 판단했나

## 0. 이 파동의 판정 기준

지시서가 준 물음은 하나다 — **"그 벤더의 제품 계열에서 원문이 밝힌 조건을 만족하는 등급이 유일한가."**
유일성은 *찾았다* 가 아니라 *세었다* 로만 증명된다고 보고, 재료마다 **계열 목록 전체를 받아 조건을 걸어 셌다.**
못 세면 안 닫힌 것으로 처리했다(§586 — 유일성을 증명 못 하면 절대 옮기지 마라).

## 1. 왜 값을 하나도 안 옮겼나

12종 전부에서 조건을 만족하는 등급이 둘 이상이었다. 가장 아까운 자리는 둘이다.

- **2274 Noryl** — 46차 HD 가 'SE1GFN2 일 개연성은 높다' 고 적어 둔 자리다. 세어 보니 20 %GF + 난연
  PPE+PS 가 **일곱**이다. 원문이 준 Tg 135 °C 로 가를 수 있을까 싶어 **일곱의 TDS 를 다 뒤졌는데
  SABIC 은 유리전이온도 행을 아예 안 찍는다**(비카트만 찍는다). 가를 축이 없다.
- **2224 PEN 200 µm** — DuPont Teijin Films 자신의 리뷰(MacDonald 2004)가 `optical grade
  polyethylene naphthalate (Teonex Q65)` 라고 적어 유력 후보가 있다. 그래도 안 옮겼다 —
  **원문이 브랜드를 안 밝혀 모집단이 안 정해지기 때문**이다(§586·§616 — "그 숫자가 이 등급 것이냐").

## 2. 왜 Hostaform 은 밀도로도 못 닫나

Celanese 제품 매뉴얼의 표준 무충전 여섯(C 2521 · C 9021 · C 13021 · C 27021 · C 36021 · C 52021)의
**비중이 전부 1.41 g/cm³** 다. 원문이 준 조성축(밀도)의 **계열 내 분산이 0** 이라 아무리 정확해도 못 가른다.
여섯을 가르는 축은 MVR(2.5~39 cm³/10min)인데 Böhm 1990 이 그 열을 안 찍는다.
덤으로 원문의 인장 74.73 MPa 는 여섯의 62~68 MPa 어디에도 안 들어간다 — 값으로 고를 길도 없다
(이 값에 이미 표시가 달려 있는 이유와 같은 자리다).

## 3. 1280·1281 은 손대지 않았다

지시서 지침대로다. 59차 UC 가 `identification_status` 와 `core_verdict_axis` 양쪽에 박아 두었고
지금도 참이다(벤더 없는 클래스 서술이라 셀 모집단이 없다).

## 4. 재료 70 `visco-6` — 표적표에 없던 15번째

라이브 V4 는 15종 91칸이고 표적표는 14종 90칸이다. 빠진 하나가 70 `visco-6`(인장강도 1칸)이며
**59차 UD 가 바로 앞 파동에 판정**해 두었다. 판정은 지금도 맞고 이번에 건드리지 않았다.

**다만 신고할 긴장이 하나 있다.** 판정문은 *"제품조차 특정 안 된다"* 인데 이 재료에는
`Technical Data 3M(TM) Viscoelastic Damping Polymer 112 Series (112P02 / 112P05)` 시트에서 온
**t1 행 넷**(박리 3 · 밀도 1)이 붙어 있고 조건에 `grade: 3M 112P02` 까지 박혀 있다(52차 NC).
둘 중 하나는 고쳐야 한다 — 시트가 이 재료의 것이면 등급이 닫힌 것이고, 아니면 그 t1 들이 계열 대입이다.
**이번 파동에서 판단하지 않았다**(내 표적표 밖이고, 어느 쪽으로 정하든 값의 등급이 움직인다).

## 5. 넣은 값 4칸의 근거

Palaniappan 1999 TABLE I 넷째 열 `Storage Modulus G' (GPa)` — 5.74 / 5.841 / 6.868 / 4.937.

- **등급 미확정과 무관하다.** 벤더 시트를 빌린 것이 아니라 **논문 자신이 그 시편에 대해 인쇄한 값**이다.
- **§602** — 같은 표의 Tg·CTE 두 열은 이미 캐 있었고 셋째 열만 남아 있었다.
- **§603** — md·`pdftotext` 어디에도 이 표의 숫자가 없다(docling 이 이미지로 남겼다). 400 dpi 렌더로 확인했다.
- **표 자신의 검산** — 본문이 `The highest storage modulus is 6.8 GPa at ... 165 °C for 60 min — about 28%
  higher than the lowest value of 4.9 GPa at 180 °C for 15 min` 이라 적고,
  (6.868 − 4.937)/6.868 = 28.1 % 가 맞는다.
- **§605 — 열의 정체.** 머리글은 `G'` 인데 **인장(굽힘) 저장탄성률 E'** 다. 근거 둘 —
  ① 같은 저자의 후속 논문(Microelectron. Reliab. 40:1181)이 본문에서 `the underfill **tensile**
  storage modulus, G'` 라고 verbatim 으로 쓴다. ② 실리카 충전 언더필의 전단저장탄성률은 2 GPa 대이고
  인쇄값 4.9~6.9 GPa 는 E' 대역이다. 우리 키 `mechanical.storage_modulus` 의 기호도 E' 다.
- **tier3 인 이유** — 형제 행(Tg·CTE)이 t3 이고 같은 표·같은 시편이다. 한 재료 안에서 규약을 가르지 않는다(§612).
- **온도를 안 붙인 이유** — 표가 경화조건마다 값 하나만 싣고 **측정 온도를 인쇄하지 않는다.**
  Tg 135~140 °C 이므로 유리상 평탄역으로 보이지만 **우리가 붙이면 우리 판정이 된다.**
  같은 재료의 CTE 행이 regime 을 안 붙인 것과 같은 규약이다(§451·612). `temperature_printed: false` 로 남겼다.

## 6. 검산 방법에서 배운 것 — WAL

`cp materialtwin.db` 로 뜬 '적용 전' 스냅샷이 **체크포인트 이전 상태**였다(41,978행 · 라이브는 42,015행).
`materialtwin.db-wal` 이 4.1 MB 였다. **스냅샷은 `sqlite3` backup API 로 떠야 한다.**
그리고 병렬 파동(60차 VC 등)이 같은 DB 를 쓰고 있어 diff 가 남의 쓰기로 오염된다 —
**라이브의 일관 사본에서 내 4행만 지워 두 번 재는 방식**으로 기여를 격리했다. 50항목 전부 동일했다.

## 7. 신고(고치지 않았다)

1. **출처 4516 의 DOI 오귀속.** 제목·연도·저자는 저널판(IEEE Trans. Electron. Packag. Manuf. 22(1) 53-62, 1999)인데
   DOI 는 학회판(48th ECTC 1998, `10.1109/ectc.1998.678805`)이다. 저널판 DOI 는 `10.1109/6104.755089`(Crossref 확인).
   **둘은 바꿔 쓸 수 없다** — 저널판 본문이 *"the equations in the prior publications have an error in the last term"*
   이라고 학회판의 수식 오류를 명시적으로 정정한다. `source.doi` 는 UNIQUE 라 고치면 자연키가 바뀐다(§578·597).
2. **60차 VC 의 정정이 무결성 항목 하나를 새로 깼다.** 재료 403 의 `mechanical.poisson_ratio`(pv 10202)와
   `thermal.expansion_linear`(pv 10203)를 t1·measured → t3·**estimated** 로 내렸는데 `notes` 는 그대로라
   `저자 추정인데 근거 없음` 이 0 → **2** 가 됐다(그 검사는 notes 에 `추정`·`estimat`·`외삽` 중 하나를 요구한다).
   **정정 자체는 옳다**(원문이 스스로 가정이라고 밝혔다). notes 한 줄만 고치면 닫힌다.
3. **재료 582 — 판정과 데이터가 어긋난다.** `verdicts_check.py` 가 잡는다.
   `core_rejected_printed_value` 가 `mechanical.tensile_strength` 를 선언했는데 같은 파동 중에 t2 digitized 3행이 들어왔다.
   내 것이 아니라 병렬 파동의 것이다(pv 43747~43749).
