## 3. 어긋난 행 — 하나씩

### FC-D1 · **직경 칸에 반지름이 앉아 있다** (2행, 고쳐야 한다)

`ed04_liebig` · Liebig 2019 · pv_id **40339**(재료 2553) · **40343**(재료 2554)

```
structure.particle_diameter = 9.89e-6 m   (음극 합제층)   tier1
structure.particle_diameter = 1.72e-6 m   (양극 합제층)   tier1
```

원문이 **같은 기호 r 을 두 곳에서 다르게 부른다.**

```
Table 3:  Particle Size    r  (µm)  9.89 ± 3.31 *3   1.72 ± 0.54 *4
Table 6:  Particle Radius  r  (µm)  9.89            1.72     ← 출처: Table 3
```

우리 키 `structure.particle_diameter` 는 정의가 **입자 직경**(`d_p`)이다.
이름만 보면 Table 3 쪽("Size")이 맞는 것 같다. **정의식으로 갈랐다**(브리프 471).

Table 6 이 같은 r 로 비표면적을 계산한다. `a = 3·ε_s / R` 에 인쇄값을 넣으면 —

| | 인쇄 a (m⁻¹) | 인쇄 ε_s | 식이 요구하는 R | 인쇄 r | r=반지름 비 | r=지름 비 |
|---|---|---|---|---|---|---|
| 음극 | 172,730 | 0.548 | 9.518 µm | 9.89 µm | **0.962** | 1.925 |
| 양극 | 825,880 | 0.457 | 1.660 µm | 1.72 µm | **0.965** | 1.930 |

**두 전극의 어긋남이 0.962·0.965 로 같다** — ε_s 반올림에서 오는 3.6 % 다.
지름으로 보면 두 전극 다 **1.93 배**, 즉 정확히 2 배로 틀어진다.
**저자는 r 을 반지름으로 썼다.** 직경 칸에 넣으려면 19.78 µm · 3.44 µm 여야 한다.

> **판정** — 지금 상태로 두면 안 된다. 지우거나(권장), 남긴다면 값을 2 배로 고치고
> tier 를 낮추면서 conditions 에 원문의 자기모순을 적어라(브리프 25·471).
> 이 배치는 **라이브 DB 읽기 전용**이라 고치지 않았다. 정정 배치로 넘긴다.
