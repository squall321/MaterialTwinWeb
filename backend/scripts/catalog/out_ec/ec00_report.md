## 0. 이 배치의 가장 큰 발견 — 그림이 벡터면 디지타이즈가 아니라 **판독**이다

세 표적의 원문 중 둘(Chen 2006 · Jung 2019)은 **그림이 래스터가 아니라 벡터**였다.
`pdfimages -list` 로 해당 페이지에 비트맵이 0개인 것을 먼저 확인했고, `pdftocairo -svg` 로 내려
경로 좌표를 그대로 읽었다. 그 결과 **축 눈금 검산 잔차가 x 0.00002 mm · y 0.0017 N 수준**으로,
래스터 디지타이즈의 화소오차(1 px ≈ 0.05 N)보다 **30배 이상 작다.**

`digitize_curve.py` 헤더가 전제하는 "지정 색과 가까운 픽셀만 곡선으로 본다"는 이 경우 필요가 없다.
**다음 배치는 그림을 열기 전에 `pdfimages -list` 를 먼저 돌려라** — 비트맵이 없으면 벡터고, 벡터면 값이 이미 파일 안에 있다.

composite 121 의 대부분이 **유리에폭시 적층판(FR-4/CCL)**이다(Panasonic R-1755·R-1566, Nan Ya NP-175, ITEQ IT-180 …).

주파수도 마찬가지다 — 읽은 x 가 0.1 / 0.2999 / 0.5003 / 0.6996 / 1.0005 / 3.0018 / 4.9994 Hz 로
원문 시험주파수 0.1/0.3/0.5/0.7/1/3/5 Hz 와 **최대 0.06 %** 차다(그래서 조건에는 공칭값을 쓰고 읽은 값을 함께 남겼다).

**본문 인쇄값과의 대조** — 원문은 `storage and loss modulus … vary between 15 kPa–226 kPa and 31 kPa–301 kPa` 라 적는다.

G″ 는 **양끝이 0.2 % 안에서 맞고** G′ 하단도 맞는데(14.56 → "15"), **G′ 상단만 226 vs 256.5 로 13.7 % 어긋난다.**
두 그림에서 독립으로 읽은 값이 0.1 % 안에서 일치하고 G″ 가 양끝 다 맞으므로 그림 쪽이 옳다고 보지만,
**우리는 원문을 고치지 않고 이 어긋남을 notes 에 적었다.**

**WLF 상수는 디지타이즈가 아니라 인쇄된 값이다** — `C1 = 10.84 · C2 = 58.17 · R² = 0.99996 · Tref 16.4 °C`.
로그 밑이 함정이었다. 원문 식 (9)는 `ln(aT) = − C1(T−T0)/(C2+(T−T0))` 로 **자연로그**인데,
바로 다음 문단은 `C1·C2 가 400~900` 이라는 **상용로그 규약의 Ferry 범위**를 근거로 곱 631 을 쓴다 — 원문 안에 규약 불일치가 있다.
**고르지 않고 수치로 가렸다**(`shift_factor_check.py`) — Fig. 9 의 원시 주파수와 Fig. 10 의 이동 주파수를
모듈러스로 짝지어 이동인자를 되뽑았고(계열마다 7점이 같은 비, 산포 0.001~0.002 decade),
그 log10(a_T) = 0 / 0.397 / 0.777 / 1.601 / 1.874 / 2.300 / 2.601 을 두 규약과 비교하니
**자연로그 잔차노름 0.41 vs 상용로그 5.91 — 식 (9) 대로 자연로그가 맞다.**
다만 되뽑은 a_T 는 3.8 °C 에서 WLF 예측(1.302)보다 0.30 decade 높아 원문의 R²=0.99996 주장과는 맞지 않는다. 이것도 적어 뒀다.

### 버린 그림 — Baek 2008 (재료 2388). **읽었는데 담을 키가 없다**

격자 156칸의 나머지 한 건이다. `Figure 1. Normalized relaxation moduli for (a) the film and (b) the substrate.` —
본문이 `Normalized shear relaxation moduli … used for the viscoelastic stress analysis` 라 못박는 **무차원 전단완화 마스터커브**이고,
ABAQUS 가 표 형태로 그대로 받는 바로 그 입력이다. 150 dpi 래스터라 연결성분으로 삼각 마커 중심을 뽑았고
**(a) 11점 · (b) 19점**, 눈금 검산 잔차 x 0.006~0.009 decade · y 0.001 이다.
자체검산 — (a)의 처음 두 점이 정확히 (0.01, 1.000) · (0.1, 0.800) 으로 떨어져 좌표계가 맞음을 보여준다.

**그런데 넣지 않았다.** 이 값은 시간 t 에서의 곡선값 g(t) 이고, DB 의 `mechanical.prony_relative_modulus` 는
`term`·`model` 축을 가진 **Prony 항의 가중치 gᵢ** 다(Σgᵢ + g∞ = 1). 곡선값을 항 가중치 칸에 넣으면 범주 오류다.
Prony 계열을 적합해 항으로 바꾸는 길이 있지만 **항 수를 우리가 정해야 하고 그건 디지타이즈가 아니라 모델 선택**이라 하지 않았다.
좌표는 `ec_baek2008_relaxation.csv` 에 남겨 뒀다 — **키만 생기면 바로 들어간다.**

## 3. `digitize_curve.py` 를 그대로 쓸 수 있었는가 — **못 썼다. 버그 하나를 포함해 셋이 모자란다**

Baek 2008 (단일 흑백 계열 · 래스터)은 이 도구의 설계 사정권 안에 있어 실제로 돌려 봤다.
크롭 후 `--color 000000 --tol 80 --logx` 로 20점을 뽑았더니 이렇게 나왔다.

```
0.00811, 0.998
767.16,  0.208     ← 두 번째 점이 벌써 767 초다
1534.3,  0.148
...  (나머지 18점이 전부 767 s 위)
```

**원인은 68행이 아니라 77행이다.**
```python
grid = np.linspace(X.min(), X.max(), n_out)      # ← 항상 선형
```
`--logx` 는 **축 매핑(64~69행)에만** 걸리고 **출력 재샘플 격자는 언제나 선형**이다.
x 가 0.008~14,580 인 로그축에서 균일 선형 격자를 깔면 20점 중 19점이 767 s 위로 몰리고
**정작 완화가 일어나는 0.01~100 s 구간이 한 점으로 붕괴한다.** 브리프가 경고한 "로그축을 선형으로 읽으면
값이 통째로 틀린다"를 **도구가 스스로 저지르고 있다.**

모자란 것 셋 —
1. **로그축 출력 격자(버그).** `--logx/--logy` 일 때 `np.geomspace` 를 써야 한다. 한 줄이다.
2. **계열 분리 수단이 색뿐이다.** Chen 2006 은 흑백 4계열이라 `--color 000000` 이 네 곡선을 한 덩어리로 만든다.
   `--probe` 자신이 "흑백 그래프면 `--color 000000`" 이라고 안내하는데, 그 안내가 다계열 흑백에서는 틀린 답이다.
   필요한 것은 **드로잉 순서·마커 모양** 기준의 분리다.
3. **열별 중앙값이 비단조 곡선을 뭉갠다.** Chen 의 하중-변위는 최대점 뒤로 되꺾이는데,
   x 픽셀열마다 y 중앙값을 취하면 최대하중이 사라진다. 이 배치가 필요로 한 값이 바로 그 최대점이다.
4. (추가) **벡터 경로 모드가 없다.** 이번 세 표적 중 둘이 벡터였고, 벡터에서는 잔차가 3~4자릿수 작아진다.
   재료 2698(구리합금 응력완화)도 같은 이유로 "벡터 그림의 마커 좌표에서 읽었다(래스터 디지타이즈 아님)"고 적혀 있다 — **두 번째다.**

이번에 쓴 것은 `parse_svg.py`(경로+transform 파서) · `extract_chen2006.py` · `extract_jung_fig9.py` ·
`extract_jung2019.py` · `extract_baek2008.py`(래스터 연결성분) 다. **전부 `out_ec/` 에 있다.**
`digitize_curve.py` 는 손대지 않았다 — 다른 배치가 쓰는 도구를 이 배치가 고칠 일이 아니다.

## 4. 다음 배치에 넘길 것

1. **`digitize_curve.py` 77행을 고쳐라.** `--logx/--logy` 일 때 `np.linspace` → `np.geomspace`. 한 줄이고,
   지금 상태로는 로그축 그림에서 나오는 값이 전부 틀린다. 고치는 김에 `--vector` 모드(pdftocairo -svg + 경로 파싱)를 붙이면
   `out_ec/parse_svg.py` 를 그대로 옮겨 쓸 수 있다.
2. **Prony 택일군에 `storage_modulus` · `loss_modulus` · `wlf_c1/c2` 를 넣을지 정해라.**
   지금 `PRONY = (prony_relaxation_time, prony_tensile_modulus, prony_shear_modulus, prony_relative_modulus, shear_modulus)` 라
   **이번에 넣은 KGK-200A50 의 96행이 그 칸을 닫지 못한다.** 점탄성이 실제로 발표되는 형태는 Prony 항이 아니라
   **DMA 스윕 + 이동인자**다. 다만 이건 지표 정의 변경이라 우리가 임의로 못 한다 — 판단이 필요하다.
3. **`mechanical.relaxation_modulus_normalized`(무차원, 축 `time_s`·`temperature_k`·`mode`) 키를 새로 만들어라.**
   Baek 2008 의 30점이 좌표까지 뽑힌 채 `ec_baek2008_relaxation.csv` 에서 기다리고 있고,
   T3~T7(아래)의 마스터커브도 전부 이 형태다. **Prony 항 칸에 곡선값을 넣는 것보다 키를 만드는 게 맞다.**
4. **디지타이즈 아닌 표적이 하나 있다 — Chowdhury 2019 (재료 617, 언더필).**
   `/data/paper_patent_corpus/structured/cae_papers/10_underfill_stress/Chowdhury - 2019 - Characterization of Viscoelastic Response of Underfill Materials/tables/` 에
   **Prony 쌍이 표로 이미 뽑혀 있다** — `table-5.md` 가 13쌍(i / τᵢ / αᵢ) 깔끔하고, table-2/4/6/7 에 7·17쌍,
   table-1/3 에 이동인자 표(100~140 °C)가 있다. **디지타이즈가 필요 없는 최고가치 한 건이다.**
   다만 docling 이 그리스문자(Į→α, Ĳ→τ)와 지수(`2.85 x 10 -1`)를 뭉갰고 table-2/4 의 bulk 열이 shear 열과
   중복된 흔적이 있으니 **PDF 원문과 대조하고 옮겨라.**
5. **격자 밖 디지타이즈 표적 T3~T7 이 있다.** 156칸 필터(`FILMISH`) 밖이라 이 격자로는 안 잡히지만 값은 실재한다 —
   Chen 2012 재료 1301(LED 봉지 실리콘, `Fig. 4 Storage modulus master curve fitting with the Prony series`, 실제 y축은
   `Relaxation Modulus (MPa)` 선형 0~30) · Watanabe 2018 재료 1430(`Fig. 5 Master curve of relaxation modulus at
   reference temperature of 414 K`, Arrhenius Q=349 kJ/mol) · Sadeghinia 2012 재료 743(EMC, `Fig. 9~12` 경화도별
   전단완화 마스터커브 7개) · Chopin 2018 재료 741·742(모델 PSA, `Figure 2` 5패널, (e)가 전단완화 마스터커브) ·
   Fuensanta 2019 재료 592~596·1175(TPU PSA 6종, `Figure 14`, 단 25 °C 한 온도 4 decade 뿐이라 tier3).
   **T3~T7 + 4번 표를 다 하면 13종 정도가 닫힌다. 154 가 아니다.**
6. **`FILMISH` 필터를 고쳐라 — DD 의 2번 권고와 같은 문제가 Prony 격자에서 더 크게 났다.**
   156칸 중 121칸이 유리에폭시 적층판이다. 적층판에 폴더블 벤딩 점탄성 완화를 요구하는 것은 해석이 아니라 필터 사고다.
   고치면 Prony 잔여는 30칸대로 내려가고 척도가 정직해진다.
7. **"디지타이즈로 캘 수 있는 천장"은 한 자릿수 %다.** 이미 가진 출처만 뒤지는 한 그렇다.
   그 위로 가려면 새 문서가 필요하고, 그 문서는 재료 논문이 아니라 **점탄성 특성화 전용 논문**이다
   (제목에 DMA·time-temperature superposition·relaxation 이 들어가는 것). BC 의 §659 통과와는 다른 검색축이다.
